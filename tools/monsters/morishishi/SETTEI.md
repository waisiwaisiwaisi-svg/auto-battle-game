# モリシシ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | くさ ／ じめん |
| もとの 生き物 | イノシシ |
| 分類 | こけやま モンスター（約57×48） |
| 性格 | ふだんは 動かず 森の 一部の ように ねむるが、なわばりに 入った ものには 地ひびきを 立てて 突進する。一度 走りだすと 止まらない |
| すみか | 深い 原生林の 苔むした 岩場。何十年も 同じ 場所に いて 背中に 木が 根を はった |

## 見た目
- 肩の 大きな こぶを 苔の 毛布が おおい、ふちから 苔が たれる。こぶの 上に 若木が 1本 生えて いる
- 背すじには たてがみの かわりに 白く かたい 根の とげが 並ぶ
- 頭は 低く 長い 鼻、平らな 鼻先。重い まゆの 下に 小さく 赤く 光る 目
- 口の はしから ねじれた 根の きばが 上へ のび、先は 後ろへ 曲がる。ひづめは 石の ように かたい

## 色（GBA風・16色以内 → 12色）
輪郭 2（黒／こげ茶）・皮 3（茶）・苔と 葉 3（緑）・根 2（白木）・目 1（赤）・白

## 動き
- 待機：背中の 若木の 葉が ゆれる（差しかえ）、胴が 上下
- 歩き：短い 足で 重く 進む
- 攻撃：頭を 低く 下げて ため（目が 燃える）→ 土けむりを 上げて 突進、口を 開く → 頭を はね 上げて きばで すくい、土くれが 飛ぶ
- 被弾：頭を 上げて のけぞる
- ダウン：ひっくり 返る（目は ×）

## ゲーム上の 目安
- HPと 防御が 高い・素早さは 低い
- 技の 例：ねっこタックル（くさ）、じならし（じめん）、こけのよろい（防御アップ・すこし 回復）
