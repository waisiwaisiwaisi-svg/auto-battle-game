# ライウンクラゲ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | でんき ／ かぜ |
| もとの 生き物 | クラゲ |
| 分類 | せきらんうん モンスター（第1形態・約51×55） |
| 性格 | 気まぐれで 執念深い。風に 乗って ただよい、気に 入らない ものの 上で 雷を 落とす |
| すみか | 夏の 海の 上空。夕立の 雲に まぎれて いる |

## 見た目
- かさは もこもこの 積乱雲。上へ もり上がる ふくらみごとに 光と 影、中で 電気の ひびが 光る
- かさの 下は 平らな 嵐の 底。ふちは クラゲの ひだ
- かさの 前に 稲妻色に 光る 目 2つと 牙の 口
- 触手は 4本の 稲妻（金色の ジグザグ）。後ろに 風の うずが 巻く
- **デフォルメ（2〜3頭身）**：かさ（頭）は 全体の 約45%。触手は 4本に へらし 太く 短く

## 足した もの／引いた もの
- 足した：雲の ふくらみ（かさ）、稲妻の 形の 触手、風の うず、するどい 目と 牙
- 引いた：細かく 長い 触手の 束 → 稲妻 4本、口腕、すきとおった 表現

## まぜた もの と 似ている 点
- クラゲの かさ ⇔ 積乱雲：どちらも「上に もこもこ ふくらむ 半球で、下が 平ら」
- 垂れる 触手 ⇔ 雲から 落ちる 稲妻：どちらも「かさの 下から 垂れ下がる 細い すじ」

## 見せ所
- 積乱雲の かさ。体の 半分ちかい 大きさで、攻撃の ときは 中の ひびが 金色に 光る

## 色（GBA風・16色以内 → 13色）
輪郭 2（黒／濃い紺）・雲 4（白 → 嵐の 灰）・稲妻 3（金）・白・電気の 水色・風の 青・口の 中の 赤

## 目
光る目（E型）が 2つ：瞳も 黒い 輪郭も ない 稲妻色の 光。白い 芯＋黄、まわりに 1ドットの こい 金の にじみ、その 外に 嵐雲の 影。顔の まん中へ 下がる くさび形で にらむ。まばたき＝光が 細い 線に、ため＝白く 大きく 燃える、被弾＝光が ひび割れて 散る、ダウン＝光が 消えて 灰色の ×

## 動き
- 待機：かさと 体が 1ドット 上下、触手が 左右に ゆれ、風の うずが 回る
- 移動：上下に ただよい、触手が うねる
- 攻撃：かさを ちぢめて 雲の 中が 光る（ため）→ 口を 開け、前へ 雷を 落とす → 火花が 残る
- 被弾：後ろへ ゆれる
- ダウン：地面に 落ちて つぶれ、触手が だらりと 横に（目は ×）

## はなれている もの（意図的）
- atk1 の 雷、atk2 の 火花は エフェクト。ダウンの だらりと した 触手は 雲の 底に ふれている

## ゲーム上の 目安
- 特殊攻撃と 素早さが 高い・防御は 低い
- 技の 例：らいうんおとし（でんき）、つむじかぜ（かぜ）、かみなりぐも（まひ）
