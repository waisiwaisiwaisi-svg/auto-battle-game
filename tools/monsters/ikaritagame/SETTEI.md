# イカリタガメ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。タガメを 「鉄の 錨の 前脚で 獲物を 引きずりこむ 沼の 狩人」に した 怪物。目は するどく。

| 項目 | 内容 |
|---|---|
| タイプ | むし ／ みず |
| もとの 生き物 | タガメ |
| 分類 | いかりむし モンスター（約56×39） |
| 性格 | しずかに 待ちぶせ、近くを 通った ものを 錨で ひっかけて 水の 底へ 引きずりこむ。いちど つかんだら はなさない |
| すみか | 古い 港の 沈んだ 船の まわりの 沼。錨は 沈んだ 船から 手に 入れたと いわれる |

## 見た目
- **デフォルメ（2〜3頭身）**：頭は 大きな くさび形、平たい 背（羽）は 小さく、泳ぐ 足は 短く 太い 2本
- 背は どろ色の 平たい だ円で、カメムシの なかまの X字の 羽の 重なり、ぬれた つや。おしりに 短い 呼吸管
- 頭の 下に 針の くちばし
- **前脚が 鉄の 錨**：虫の もも → 錨の 輪が ひざの 関節 → 柄 → かぎの 2本爪。いつも 地面に 立てて かまえる
- 泳ぐ 足の すそに 水色の 毛
- **目**：白い 光＋金 2段＋たての ひとみ、まゆと 下まぶたの 線
- **つなぎ方**：ももは 胸に 食いこみ、先は 錨の 輪に 重なる（輪が 関節）。足は 背に 3ドット 食いこむ。攻撃の 水しぶきだけは はなれているのが 意図的（エフェクト）

## 足した もの／引いた もの
- 足した：鉄の 錨（前脚の すね・かま の かわり）
- 引いた：泳ぐ 足 4本 → 2本、触角、羽の 細かい 脈

## まぜた もの と 似ている 点
- タガメの 前脚の かま ⇔ 錨の かぎ：どちらも **内向きに 曲がる かぎ爪で ひっかけて はなさない**。かまの 先を 錨の 2本爪に、ひざを 錨の 輪に した

## 見せ所
- **鉄の 錨の 前脚**（体の 高さの 3/4 ほど。攻撃では 90度 ふり出して 前へ 打ちこむ）

## 色（GBA風・16色以内 → 13色）
輪郭 2（黒／こい 茶）・体 3（どろ色）・鉄 3・水 2・目 2（金）・白

## 動き
- 待機：背が 上下し、錨が かすかに 上下する
- 歩き：短い 足を 交互に、錨を 引きずって 進む
- 攻撃：錨を 引いて ため（目が 光る）→ 錨を 横に ふり出して 前へ 打ちこむ → 水しぶき
- 被弾：頭を そらして のけぞる
- ダウン：ひっくり 返る（目は ×）

## ゲーム上の 目安
- 攻撃と 防御が 高め・素早さは 低い
- 技の 例：いかりおとし（みず）、ひきずりこみ（むし・相手を 逃がさない）、ぬまがくれ
