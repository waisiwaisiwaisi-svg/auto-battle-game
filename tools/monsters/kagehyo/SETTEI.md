# カゲヒョウ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | あく |
| もとの 生き物 | ヒョウ |
| 分類 | かげまだら モンスター（約56×34） |
| 性格 | 冷酷な 狩人。音も なく 影から 影へ うつり、獲物の 背後から とびかかる。満月の 夜は 姿を 見せない |
| すみか | 深い 密林の 木かげ。昼でも 暗い 場所を 好む |

## 見た目
- **デフォルメ（2〜3頭身）**：頭は 大きい まま（たて 17・全体の 約半分）、胴は 低く しなやかに 細長く（腹は しぼる）。足は 短いが 「く」の 字に 曲げた ふせの かまえ
- **はなれた パーツ**：攻撃の 影の 爪あとは エフェクトなので はなれているのが 意図的
- 目は まゆの ひさしの 下、光（白）＋ 虹彩 2色（黄緑／深緑）＋ たての ひとみ＋下まぶた
- 足は 上の 3行を 胴の 中に 食いこませて つなぐ。うしろ足は もも→ うしろへ 引いた すね→ かかと→ 前へ 出した 足先、前足は 太い 肩→ ひじ→ ななめ 前の うで→ 大きな 足先。どの 足先にも 白い 爪。奥の 足は 暗い 色で 少し ずらし、柱が 4本 ならぶ 形に しない
- 体は 夜の 色（藍〜すみれ）。斑点は 穴の ように 真っ黒な 「影」で、ふちが 紫に 光る
- 肩が 盛り上がり、背中で へこみ、ももが 少し 高い 獲物を ねらう 姿勢
- 頭は 低く、まゆの 下で 黄緑に 光る つり目。口は 赤く さけて 牙が のぞく。肩の 斑点から 黒い **影の ほのお** が 立ちのぼる（根もとは 背中に 食いこむ）
- しっぽは 長く、先が 上へ くるりと 巻く

## 色（GBA風・16色以内 → 10色）
輪郭 2（黒／暗い 藍）・毛 3（藍〜すみれ）・影の 斑点 1（黒）・光る ふち 1（紫）・目 1（黄緑）・口 1（赤紫）・白（牙・爪）

## 動き
- 待機：肩の 影の ほのおが ゆらぐ（差しかえ）、胴が 上下
- 歩き：低い 姿勢で しのび 足
- 攻撃：胴を 地面すれすれまで ふせて ため（目が 光る）→ 前足を のばして とびかかり、口を 開く → 着地と 同時に 紫の 影の 爪あと
- 被弾：頭を 上げて のけぞる
- ダウン：その場に ふせる（目は ×）

## ゲーム上の 目安
- 素早さと 攻撃が 高い・防御は 低め
- 技の 例：かげづめ（あく：急所に 当たりやすい）、しのびより（先制）、くろいもや（回避アップ）
