# デンタマ

| 項目 | 内容 |
|---|---|
| タイプ | でんき／エスパー |
| もとの もの | 電球（白熱電球・無機物） |
| 分類 | ひらめきモンスター（S、約35×43） |
| 性格 | 好奇心が 強く、思いつくと すぐ 動く。ひらめいた 瞬間 ぴかっと 光る |
| すみか | 古い 研究所・街灯の 上。停電の 夜に 集まって くる |

## 見た目
- まるい ガラスの 玉と すぼまった 首、銀の **ねじの 口金**、先に 接点。ガラスの 中の **フィラメントが 顔**
- 目は **光る フィラメント目**：白〜黄〜赤橙に 光る 輪の 中に こげ茶の ひとみ（右を 見る）。口は 光る フィラメントの 線、その 両はしから 2本の 導線が ステム（ガラスの 台）へ のびる
- 顔の まわりが いちばん 明るく、ガラスの 右下は こがね色。左上に 白い つや。ほっぺに ピンク
- まわりに 黄色い 火花（でんき）と 紫の きらめき（エスパー）

## 足した もの／引いた もの
- 足した もの：フィラメントの 顔、ほっぺ、まわりの 火花
- 引いた もの：手足（浮いて いるので なし）、ガラスの 中の 細かい 支え線

## まぜた もの と 似ている 点
- フィラメントと 導線 ⇔ 目・口・ひげの ような 顔
- 電球が つく ⇔ 「ひらめき」（エスパー）

## 見せ所
- 攻撃で ガラス全体が 白く ぴかっと 光る ところと、ダウンで 灯りが 消えて 銀色に なる ところ

## 色（15色）
- ともった ガラス 3段（白〜うす黄〜こがね）・銀 3段（口金、消えた ガラスにも 使う）・黒・茶（輪郭）・フィラメント 4段（こげ茶・赤橙・黄・白）・ピンク（ほっぺ）・紫（念力）・灰（けむり）

## 動き
- 待機：ふわふわ 上下、火花が 場所を 変えて ぱちぱち、口金の 下に 小さな 火花
- 歩く：前へ ただよう（上下 しながら 少し 前へ）
- 攻撃：うしろに 引いて 紫の 念力の 輪を ため、目が つり上がる → ガラスが 白く ぴかっと 光り、光の すじと いなずまを 飛ばす → いなずまが 2本に わかれて 前へ、念力の 波
- 被弾：うしろへ はじかれ、目は「＞＜」、火花が 散る
- ダウン：横だおしで 灯りが 消え（ガラスが 銀色に）、けむりが 出る。目は ×
- 火花・いなずま・光の すじ・念力の 輪が 体から はなれているのは 意図的（エフェクト）

## ゲーム上の 目安
- すばやさ・とくこう 高め、ぼうぎょ 低め。いなずまで 先手を とる アタッカー
