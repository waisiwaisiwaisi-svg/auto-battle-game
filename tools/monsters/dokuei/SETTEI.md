# ドクエイ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | どく ／ みず |
| もとの 生き物 | エイ（アカエイ） |
| 分類 | どくばり モンスター（第1形態・約62×43） |
| 性格 | 海底の 砂に ひそんで 待ちぶせる。ふまれると 尾を さそりの ように 振り上げ、毒針で 何度も 突く |
| すみか | 浅い 海の 砂地や、毒の 沼と つながる 入り江 |

## 見た目
- **デフォルメ（2〜3頭身）**：エイの 前に 大きな 頭（前へ つき出た 頭びれ・つり目・牙の 口）を つけ、つばさは 小さく まとめる。頭は つばさに 食いこみ、境めは 輪郭で なく 影の 線。毒針の 尾は 大きい まま
- **目**：目は 白い 光＋金 2段（明・暗）＋たての ひとみ。黒い まゆの ひさしと 下まぶたで かこむ（手前は 大きく、奥は 小さく）
- **はなれた パーツ**：毒の しずく・毒しぶき・砂けむりは はなれているのが 意図的（手足・首・尾・翼は 体に 食いこませて つなぐ）
- やじりの 形の 平たい 体（3/4 上から 見る）の 前に 大きな 頭。奥の つばさは 上、手前の つばさは 下で、裏の 白い ふちが 見える
- 背は 暗い 青緑。つばさに 毒の ふくろが 赤紫に 光って 並ぶ（どくタイプ）
- 背骨の 稜線が 光り、頭の 上に 金色の つり目と 毒の いぼ。下に 牙の ならぶ 口
- 長い 尾は さそりの ように 上へ 反り返り、先に ぎざぎざの 返しの ついた 骨の 毒針。針先から 毒が したたる
- 海底すれすれを すべり、砂けむりと 泡を 立てる（みずタイプ）

## 色（GBA風・16色以内 → 14色）
輪郭 2（黒／濃い紫紺）・背 3（青緑）・裏の 白・毒 3（桃・赤紫・暗紫）・目 2（金・明／暗）・骨 2（毒針）・泡（水色）

## 動き
- 待機：つばさの 3つの 区切りが 順に 1ドット 波うち、毒針から 毒が したたる
- 移動：つばさの 波が 前から うしろへ 流れ、海底に 砂けむり
- 攻撃：尾を うしろへ 引きしぼり、毒針と 毒の ふくろが 光る → 尾を 体の 上から 前へ 振りおろして 突き刺す（毒しぶき）→ 突き刺したまま 押しこむ
- 被弾：うしろへ 下がり、つばさの 前が はね上がる
- ダウン：ひっくり返る

## ゲーム上の 目安
- 防御と 素早さが 高め・攻撃は ふつう
- 技の 例：どくばりづき（どく・もうどく）、すなかくれ（回避アップ）、うずしおすべり（みず）
