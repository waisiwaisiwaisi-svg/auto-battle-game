# ハガネハリネズ

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | はがね |
| もとの 生き物 | ハリネズミ |
| 分類 | やいばばり モンスター（第1形態・約50×38） |
| 性格 | 臆病そうに 見えて 気性は するどい。近づく ものには だまって 背中の 刃を 逆立てる |
| すみか | 鍛冶場の すてられた 鉄くず置き場。研ぎ石の 岩で 針を 毎日 とぐ |

## 見た目
- **デフォルメ（2〜3頭身）**：頭を 大きく 描きなおし（たて 17・全体の 約45%）、胴は 小さく 丸く、足は 短く 太い。刃の 針は 見せ所なので 長い まま（根もとは 胴の 中へ うめる）
- 目は ビーズ目＋太い まゆ：小さく 真っ黒な つぶ目に 強い 白の ハイライトが 1点。その 上に 鉄色（白銀／灰／暗い 鉄）の 太い まゆが 前へ ななめに さがり、怖く にらむ
- 攻撃で 飛ばす 刃は エフェクトなので はなれているのは 意図的
- 背中 一面に 13本の 刃の 針。1本ずつが 包丁の ような 平たい 刃で、先は 冷たく 青白く 光る（はがね）
- 体は 小さく 丸い。皮ふは 赤紫で、腹は 明るい
- 頭は 大きな くさび形。鉄の 太い まゆの 下で 黒い ビーズ目が 光る
- 口は 横に さけ、上と 下に きば
- 足は 短く、つめは はがね

## 色（GBA風・16色以内 → 12色）
輪郭 2（黒／赤紫の こげ色）・刃 3＋刃先の 光 1・皮ふ 3・目の 黒 1・目の 光（赤＝攻撃）・白

## 動き
- 待機：刃の 針が 1ドット 上下し、刃先の 光が またたく
- 歩き：短い 足で ちょこちょこ 進み、体が はずむ
- 攻撃：身を ふせ、針を 長く 上へ 逆立てる（鉄の まゆが さらに さがり、目の ハイライトが 青白く、瞳に 赤い 光）→ 刃の 針を 2本 前へ 飛ばす → 針が 遠くへ 飛んで いく
- 被弾：頭が はね上がり、針が くずれる
- ダウン：ひっくり 返る（目は 小さな 黒い ×、まゆは 残る）

## ゲーム上の 目安
- 防御と 素早さが 高い。体力は ひくめ
- 技の 例：はりとばし（はがね）、さかだて（防御アップ・ふれた 相手に ダメージ）、かみつく（ノーマル）
