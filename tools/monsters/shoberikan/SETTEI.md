# ショベリカン

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | ノーマル ／ みず |
| もとの 生き物 | ペリカン |
| 分類 | ショベル モンスター（約56×55） |
| 性格 | 食いしんぼうで なんでも すくって のみこむ。じゃまな ものは 船ごと くちばしで すくい あげる |
| すみか | 港の 防波堤と 工事中の 埋め立て地 |

## 見た目
- 下くちばしの 袋が 鉄の ショベルの バケット。後ろが まるく、上が 平らに ひらき、前の ふちに 鉄の 歯が 3本 つき出る。補強の 帯と 鋲
- 上くちばしは 黄色く 長く、先が かぎ形
- 頭は まるく 白い。とげの ような 冠羽、黒い まゆが 前へ 下がった 金の つり目
- 胴は 小さく まるく、たたんだ 翼の 先は 灰青の 風切り羽。足は 短い だいだいの 水かき
- **デフォルメ（2〜3頭身）**：頭と くちばし（バケット）を 大きく、首と 胴と 足は 短く
- 目は 白い 光＋金と だいだいの 虹彩＋たての ひとみ、まゆと 下まぶたの 線

## 足した もの／引いた もの
- 足した：鉄の バケットと 歯、バケットの 中の 水（みず）
- 引いた：長い 首と 長い 足を 短く し、翼の 羽の 枚数を 3枚に まとめた

## まぜた もの と 似ている 点
- ペリカンの のど袋 ⇔ ショベルの バケット：どちらも「下に ぶら下がって ものを すくう 入れもの」。袋の 形を そのまま 鉄の バケットに おきかえた

## 見せ所
- **鉄の バケットの くちばし**。攻撃で 上くちばしが 上がり、中の 水を 見せて → 前へ 水を ぶちまける

## はなれた パーツ（意図的）
- 攻撃の 水しぶき（エフェクト）だけ

## 色（GBA風・16色以内 → 13色）
輪郭 2（黒／こい 青灰）・羽 3（白〜灰青）・くちばし／足 2（黄／だいだい：目も）・鉄 3・水 2・白

## 動き
- 待機：頭が 上下、翼が 少し 上がる
- 歩き：水かきの 足を 交互に、頭を ゆらして 進む
- 攻撃：頭を 後ろへ 引いて ため（くちばしが 少し 開き 目が 光る）→ 頭を つき出して バケットで すくい、水を ぶちまける → しぶきが 前へ
- 被弾：後ろへ のけぞり、目は くの字
- ダウン：ひっくり 返る（目は ×）

## ゲーム上の 目安
- 攻撃・HPが 高め、素早さは ひくめ
- 技の 例：バケットすくい（ノーマル）、みずぶちまけ（みず）、まるのみ（ノーマル）
