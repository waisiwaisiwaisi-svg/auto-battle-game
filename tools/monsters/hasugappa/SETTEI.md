# ハスガッパ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | くさ ／ みず |
| もとの 生き物 | 河童（架空） |
| 分類 | はすざら モンスター（第1形態・約52×52） |
| 性格 | 気が 短く いたずら好き。池に 近づく ものを 水かきの 爪で 引きずりこむ |
| すみか | 蓮の 池・沼。蓮の 葉の 下に ひそむ |

## 見た目
- 頭の 皿は 大きな 蓮の 葉（まん中から すじ、前に 切れこみ、しずくが のる）
- 黄色い くちばしは ぎざぎざ、赤い 半目（重い まぶた）
- 背中の 甲羅は 蓮の 実（穴から 種が のぞく）
- **水かきの 大きな 爪の 手**（見せ所）：3本の 太い 指に 白く するどい 爪、指の 間に 膜
- **デフォルメ（2〜3頭身）**：頭（皿を ふくむ）は 全体の 約45%。胴は 小さく 丸く、足は 短く 太い

## 足した もの／引いた もの
- 足した：蓮の 葉の 皿、蓮の 実の 甲羅、白い 爪
- 引いた：頭の 毛、甲羅の 細かい 模様、うしろの 手の 指（小さく まとめる）

## まぜた もの と 似ている 点
- 河童の 皿 ⇔ 蓮の 葉：どちらも「頭の 上の 丸く 平らな 板」
- 河童の 甲羅 ⇔ 蓮の 実：どちらも「背中に しょう 丸い かたまりに 穴の 模様」

## 見せ所
- 前の 手。頭と 同じ くらいの はばに 広がる 水かきと 爪。攻撃では 水の 斬撃を とばす

## 色（GBA風・16色以内 → 16色）
輪郭 2（黒／濃い緑）・肌 3（みどり）・葉の 光・蓮の 実 3（黄土）・くちばし 2（黄・だいだい）・目 2（赤）・白・水 2（水色・青）

## 目
重い まぶた（M型）：ぶあつい みどりの 上まぶたが 赤い 虹彩の 上半分を おおい、下半分の 赤い 目と 黒い 瞳だけで 冷たく 見下ろす。まばたき＝まぶたが 全部 おりる、ため＝まぶたが 少し 上がって 赤く 光る、被弾＝まぶたが ゆがむ、ダウン＝×

## 動き
- 待機：胴が 1ドット 上下、皿の しずくが ゆれる、手が 上下
- 歩き：短い 足を 交互に、頭が 弾む
- 攻撃：手を 下へ 引いて ため → 前へ 爪を ふり、口を 開けて 水の 斬撃 → しぶき
- 被弾：頭を 後ろへ そらす
- ダウン：ひっくり 返る（目は ×）

## はなれている もの（意図的）
- atk1 の 水の 斬撃、atk2 の しぶきは エフェクト

## ゲーム上の 目安
- 攻撃と 体力が 高め・素早さ ふつう
- 技の 例：はすのかまいたち（くさ）、みずかきクロー（みず）、ひきずりこみ（相手を 動けなく する）
