# ヒョウジンペンギン（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | こおり ／ はがね |
| もとの 生き物 | ペンギン |
| 分類 | ひょうじん モンスター（第1形態・約52×47） |
| 性格 | 冷たく 気位が 高い。氷の 上を すべるように 近づき、刃の ひれで 一気に 切りつける |
| すみか | 氷河の 割れ目。鋼の 刃を 氷で とぎ続けている |

## 見た目
- 紺の 羽の ペンギン。腹は 氷の 白で、うろこ状の 氷の 模様
- **左右の ひれが 鋼の スケートの 刃**。平たく 細い 板で、下の ふちが 白く 光る 刃、先に ぎざぎざ（トウピック）。付け根は 鋲の 関節で 胴に 食いこむ
- 頭に 氷の 結晶の とさか（3本）。くちばしは 鋼の 刃で、下の ふちに ぎざぎざの 歯
- 目は 白い 光＋水色と 青の 2段の 虹彩＋ひとみ、上まぶたの 線で つり目に かこむ
- **デフォルメ（2〜3頭身）**：頭は 大きく 胴と 同じ はば、胴は たまご形で 小さく、足は 短い。刃の ひれ（見せ所）は 大きい まま

## 足した もの／引いた もの
- 足した：鋼の 刃の ひれ（はがね）、氷の 結晶の とさか（こおり）、刃の くちばし
- 引いた：羽毛の 細かい 模様・首の 長さ・足の 水かき

## まぜた もの と 似ている 点
- ペンギンの ひれ ⇔ スケートの 刃：どちらも「平たく 細い 板」。ひれの 形を そのまま 鋼に して、下の ふちを 刃に した

## 見せ所
- 体の 前に 長く のびる 鋼の 刃の ひれ（体の 高さほど ある）。攻撃では 前へ まっすぐ 突き出して 切る

## はなれている もの（意図的）
- 攻撃の 氷の 斬撃（弧）は エフェクトなので はなれているのが 意図的
- ひれ・足・とさかは 胴や 頭に 2〜3ドット 食いこませて つないである

## 色（GBA風・16色以内 → 16色）
輪郭 2（黒／濃い紺）・羽 3（紺）・腹 2（氷の 白）・鋼 3・氷 2（水色）・足 2（だいだい）・白・口の 中

## 動き
- 待機：胴が 上下し、刃の ひれが 1ドット 上下に ゆれる
- 歩き：短い 足を 交互に 上げて よちよち、胴が 左右に ゆれる
- 攻撃：ひれを 後ろへ 引いて ため（目が 光る）→ 前へ すべりこみ 刃を まっすぐ 突き出す → 氷の 斬撃
- 被弾：頭を 引いて 後ろへ のけぞる
- ダウン：前へ ばったり たおれて 腹ばいに なる（目は ×）

## ゲーム上の 目安
- 攻撃と 防御が 高い・素早さは ふつう
- 技の 例：ひょうじんぎり（こおり）、はがねの ひれ（はがね）、こおりすべり（先制）
