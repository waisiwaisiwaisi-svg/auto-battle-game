# ヒサソリ

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 虫ではなく、サソリを 「焼けた 毒針で しとめる 怪物」に した。目は するどく。

| 項目 | 内容 |
|---|---|
| タイプ | ほのお ／ どく |
| もとの 生き物 | サソリ |
| 分類 | しゃくねつどくばり モンスター（第1形態・約58×50） |
| 性格 | しつこく 待ちぶせる 狩人。えものを 見つけると 背板の すき間の 熾火が 強く 光る |
| すみか | 火山の ふもとの 熱い 砂地。岩の 割れ目で 体を 熱に ならして いる |

## 見た目
- 体は 赤銅色の 背板が 4枚 つらなり、板の すき間から 熾火（おきび）が もれる。背すじに 先の 焼けた 短い とげ
- 頭は 平たい よろいで、顔の 横に 大・中・小・豆の 4つの 赤い 目が 前へ 並ぶ（目の種類 N 多眼）
- はさみは 大きく、内がわに 白い ぎざぎざの 歯。はさみの すき間で 火花が はじける
- しっぽは 5つの 節で、節ごとに 熾火の ひび。先の 毒ぶくろは 紫に ふくらみ、毒針は 白熱して 黄色く 光る
- 足は 左右 4本ずつ、細く 折れ曲がって 低く かまえる
- **デフォルメ（2〜3頭身）**：頭を 大きな まるい かぶとに 描き直し（後ろへ 反った 角 2本）、腹は 背板 3枚に 短く、足は 短く 太く。はさみと しっぽ（見せ所）は 大きい まま
- 目は 黒い ふちの つやつやの 赤い 玉（瞳なし）。大きい 2つには 白い 光と 暗い 赤の かげ。攻撃の ためでは 4つとも 熾火の 黄・だいだいに 光り、被弾では つぶれ、ダウンでは 大きい 目が ×

## 色（GBA風・16色以内 → 11色）
輪郭 2（黒／こげ赤）・こうら 3・熱 2・毒 3・白（歯）

## 動き
- 待機：しっぽが ゆれ、背板の 熾火と はさみの 火花が 明滅
- 歩き：足を 2組 交互に 動かして ちょこまか 進む、はさみも 交互に ゆれる
- 攻撃：しっぽを 後ろへ 引きしぼり（目が 全開で 光る）→ 頭ごしに 白熱の 毒針を 前へ 突き出す → 針先で 毒と 火の しぶきが はじける
- 被弾：しっぽが 後ろへ そり、はさみが 下がる
- ダウン：あおむけに ひっくり 返る（目は ×）

## ゲーム上の 目安
- 攻撃・素早さが 高め、防御は ふつう
- 技の 例：しゃくねつばり（ほのお）、どくばりづき（どく）、ひばなばさみ（ほのお）
