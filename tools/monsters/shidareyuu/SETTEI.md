# シダレユウ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | ゴースト ／ くさ |
| もとの 生き物 | 柳（しだれ柳） |
| 分類 | ゆうれいやなぎ モンスター（約47×56・M） |
| 性格 | しずかで 陰気。夜の 水辺で 長い 髪の ような 枝を たらし、近づいた ものを 垂れ枝の 爪で からめ取る。にたりと 笑うが 目は 笑っていない |
| すみか | 古い 堀や 川ばたの 柳並木。ひとだまの ような 霊火が まわりを ただよう |

## 見た目
- 頭は 柳の かんむり。そこから 背中・地面ちかくまで 垂れる 枝の 束が 幽霊の 長い 髪に なっている（見せ所）。前がみの 葉先が 顔に かかる
- 顔は 青白い 幽霊の 顔。枝の あいだから 黄みどりに 光る つり目、にたりと 笑う 口に きば
- 胴は 短く ねじれた 幹、足は 3本ゆびの 太い 根。腕は 枝で、先に 垂れ枝の 長い 爪が 3本
- **デフォルメ（2〜3頭身）**：髪の かんむり＋顔 で 頭は 約48%（27/56）。幹の 胴を 小さく、根の 足は 短く 太く した
- 目は 白い 光＋黄と みどりの 虹彩＋たての ひとみ、まゆと まぶたの 線で かこむ

## 足した もの／引いた もの
- 足した もの：幽霊の 顔と 霊火（ゴースト）、枝の 腕と 爪
- 引いた もの：幹の 高さ・枝わかれ・葉の 1枚1枚（すじの 線に まとめた）

## まぜた もの と 似ている 点
- 柳の 垂れる 枝 ⇔ 幽霊の 長い 髪。どちらも「上から 下へ まっすぐ 垂れる 何本もの 筋」。かんむりから 垂れる 枝を そのまま 髪に した

## 見せ所
- 垂れ髪（垂れる 柳の 枝の 束）。体の 半分 以上を おおう 大きさで、縦の すじと とがった 先で 目立たせる

## はなれている パーツ
- **頭の 左上に 浮かぶ 小さな 霊火（ひとだま）は 意図的に はなれている**（ゴーストの ふんいき の エフェクト）。攻撃の ひっかき エフェクトも はなれる。腕・根・髪は 幹や 頭に 食いこませて つないでいる

## 色（GBA風・16色以内 → 14色）
輪郭 2・柳の 葉 3・幽霊の 顔 2・幹 3・目 2（黄／みどり）・口の 赤・白

## 動き
- 待機：垂れ髪の 先が ゆれる（差しかえ）、霊火が 上下に ただよう
- 歩き：根の 足を 交互に すって 進む
- 攻撃：身を 引いて 腕を ふりかぶる（目が 全開）→ 枝の 腕を 前へ のばし、口が 耳まで さける・葉の 爪あと → ふりぬき
- 被弾：頭を のけぞらせ 目を 閉じる
- ダウン：ひっくり 返る（目は ×）

## ゲーム上の 目安
- HPと 特防が 高い・素早さは 低い
- 技の 例：しだれづめ（くさ）、うらみの まなざし（ゴースト）、ねをはる（回復）
