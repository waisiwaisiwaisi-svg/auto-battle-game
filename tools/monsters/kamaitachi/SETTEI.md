# カマイタチ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | かぜ ／ はがね |
| もとの 生き物 | イタチ（妖怪 かまいたち） |
| 分類 | つむじがま モンスター（約51×40・デフォルメ） |
| 性格 | すばしこく 気まぐれ。つむじ風に のって あらわれ、気づかれる 前に 切りつけて 消える |
| すみか | 風の 強い 峠道。岩かげに ひそみ、通る ものを 待ちぶせる |

## 見た目
- しなやかな 胴（デフォルメで 短く 丸い）に 短い 首。前足は 鋼の 三日月の 鎌に なっている（手前の 鎌は 高く かまえ、奥の 鎌は 地面に つき立てる）
- 背すじに 小さな 鋼の 鎌の ひれが 2枚
- 顔は 目を つつむ 黒い 仮面の 隈取りに 赤く 光る 目、とがった 耳、細い 牙
- しっぽは 太い 房で 上へ 弧を 描き、先に 小さな つむじ風（竜巻）が うずまく

## デフォルメ（2〜3頭身）
- 細長い 胴（34）を 短く 丸く（22）、長い 首を 短く。頭は 16×11 → 21×15 に 大きく 描き直し（くまどり・牙・耳は そのまま）
- 頭の 高さ 15／全体 40（約38%）。後ろ足は 短く 太く、鎌の 腕と 地面に つき立てた 奥の 鎌、竜巻の しっぽ（見せ所）は 元の 大きさ
- 目は **L 隈取りの 目**：黒い 仮面（色を 1つ 追加）が 目を つつみ、後ろの 上へ はね上がる。中に 白目の ある つり目、赤と 暗い 赤の 虹彩に 黒い 丸い ひとみ。目の 下から ほおへ 赤い すじ
- はなれているのは 意図的：しっぽの 先で うずまく 小さな 竜巻（風の かたまり）、攻撃の 風の 刃（エフェクト）

## 色（GBA風・16色以内 → 13色）
輪郭 2（黒／こげ茶）・毛 3（赤茶）・腹 1（クリーム）・鋼 3・風 2（水色）・目 2（赤・暗い 赤）・黒い 仮面 1

## 動き
- 待機：しっぽの 先の つむじ風が 回る（差しかえ）、鎌が 1ドット 上下
- 歩き：短い 後ろ足と 奥の 鎌で すべるように 進む
- 攻撃：後ろに 引いて 鎌を 高く ふりかぶる（目が 光る）→ とびこんで 鎌を ふりおろし、三日月の 風の 刃を 飛ばす → 刃が 細く なって 消える
- 被弾：首を 引いて のけぞる
- ダウン：その場に ふせる（目は ×）

## ゲーム上の 目安
- 素早さと 攻撃が 高い・防御と HPは 低め
- 技の 例：かまいたち（かぜ：急所に 当たりやすい）、はがねぎり（はがね）、つむじかぜ（素早さアップ）
