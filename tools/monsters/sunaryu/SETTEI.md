# スナリュウ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | ドラゴン ／ じめん |
| もとの 生き物 | オオトカゲ |
| 分類 | さきゅうりゅう モンスター（約64×39・L） |
| 性格 | しんぼうづよく 待ちぶせ型。砂に 体を うめて 背の 砂丘だけ 出し、近づいた えものに 大あごで 食らいつく |
| すみか | 大砂漠の 砂丘地帯。背中の 砂丘で 本物の 砂丘に まぎれる |

## 見た目
- 頭は 平たく 長い オオトカゲの 頭。上下の 太い あごが くさび形に 開き、太い きばが ならぶ（見せ所）
- 背中は 砂を まとった 3つの 山（砂丘）。なだらかな 山の 列に 風もんの すじ
- 胴は こげ茶の うろこに 砂色の はんてん。短く 太い 足が 横へ ふんばり、3本の 大きな 爪
- **デフォルメ（2〜3頭身）**：頭は 約50%（20/39）、はば ≒ 胴。胴は 小さく 丸く、足は 短く 太く。L なので 横長
- 目は 白い 光＋金と 赤の 虹彩＋たての ひとみ、重い まゆの ひさしと まぶたの 線

## 足した もの／引いた もの
- 足した もの：背の 砂丘（じめん）、大あごと 太い きば（ドラゴン）
- 引いた もの：長い しっぽ（短く した）、首の 長さ、うろこの 1枚1枚

## まぜた もの と 似ている 点
- 背の 段の うろこ ⇔ 砂丘の 波。どちらも「なだらかな 山が ならぶ 列」。背の うろこの 列を そのまま 砂丘の 山に した

## 見せ所
- 大あご。頭の 半分を くさび形の 口に し、攻撃で 上下に 大きく 開く

## はなれている パーツ
- なし（砂丘・しっぽ・足は 胴に 食いこませて つないでいる）。攻撃の 砂けむりだけ エフェクトとして はなれる

## 色（GBA風・16色以内 → 15色）
輪郭 2・うろこ 3・砂丘 3・はんてん・口 2（赤／舌）・目 2・きば 2（白／灰）

## 動き
- 待機：砂丘の 風もんが 動く（差しかえ）、頭が 上下
- 歩き：横へ ふんばった 足を 交互に
- 攻撃：頭を 上げて ため（目が 全開）→ 大あごを 開いて とびかかる・砂けむり → ふりぬき
- 被弾：頭を のけぞらせる
- ダウン：ひっくり 返る（目は ×）

## ゲーム上の 目安
- 攻撃と 防御が 高い・素早さは 低い
- 技の 例：すなあらし（じめん）、だいあごクラッシュ（ドラゴン）、すなにもぐる（回避アップ）
