# ヤイバクワ

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。虫かごの クワガタではなく、鋼の よろいを まとい 刀の あごで 斬る 「むしの 侍」の 怪物に した。目は するどく。

| 項目 | 内容 |
|---|---|
| タイプ | むし ／ はがね |
| もとの 生き物 | クワガタムシ |
| 分類 | かたなあご モンスター（第1形態・約59×34） |
| 性格 | 誇り高く 一騎打ちを 好む。にらみあうと あごを 大きく ひらき、ひと太刀で 勝負を つける |
| すみか | 鉄を ふくむ 赤土の 山の 古い 森。鉄分の 多い 樹液で 体を きたえる |

## 見た目
- 体は 青みがかった 鋼の 板を 重ねた よろい。板の さかい目を 赤い おどし（よろいの ひも）が つづる
- 頭は ひらたく 角ばり、後ろに とがった 飾り（かぶとの 鍬形の ように）。重い まゆの 下に 赤く 光る つり目
- あごは 2本の 刀。根もとに 金の つば、刃は 反りが あり、内がわの 刃先が 白く 光る
- 足は 6本。とげの ある 細い 鋼の 足で 低く かまえる

## 色（GBA風・16色以内 → 12色）
輪郭 2（黒／こい鋼）・鋼 3・おどし 2（赤）・金の つば 2・目（赤）・斬撃 1（水色）・白（刃先）

## 動き
- 待機：呼吸で 体が 上下し、刃先が きらりと 光る
- 歩き：足を 2組 交互に 動かし、胴が はずむ
- 攻撃：身を ひいて 刀の あごを 上下に 大きく ひらく（目が 全開）→ 前へ ふみこみ あごを とじて 斬る（白い 斬撃の 弧）→ ふりぬきの 残光
- 被弾：頭を さげて 後ろへ さがり、あごが ひらく
- ダウン：あおむけに ひっくり 返る（目は ×）

## ゲーム上の 目安
- 攻撃・防御が 高い・素早さは ふつう
- 技の 例：はさみぎり（むし）、はがねのやいば（はがね）、いあいのかまえ（次の 攻撃を 急所に しやすく）
