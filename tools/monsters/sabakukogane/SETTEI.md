# サバクコガネ

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。ふんを 転がす 小さな 虫ではなく、砂を 岩の ように かため 大玉に して ぶつける 「砂漠の 遺跡の 番人」の 怪物に した。目は するどく。

| 項目 | 内容 |
|---|---|
| タイプ | じめん ／ むし |
| もとの 生き物 | スカラベ（フンコロガシ） |
| 分類 | たいようえんばん モンスター（第1形態・約45×50・デフォルメ） |
| 性格 | 無口で 根気づよい。日が のぼると 角の 円盤に 熱を ため、なわばりの 砂丘を 見はる |
| すみか | 砂に うもれた 古い 遺跡。日中は 熱い 砂の 上、夜は 砂に もぐる |

## 見た目
- 背中は 砂金色の ひらたい 前ばね。たての みぞが はしり、すそは トルコ石の ふちどり
- 頭の 上に 三日月の 形の 角が 2本 立ち、そのあいだに 太陽の 円盤を かかえる。円盤の ふちには 光の とげ、中心に トルコ石
- 頭の 前は くまでの ような ぎざぎざの 刃（頭楯）。刃の 下に 白い 歯
- 目は 頭の よろいの 下で トルコ石色に 光る 複眼
- 足は 6本。前足は くまでの ように 歯が ならび、砂を かき集める

## デフォルメ（2〜3頭身）
- 前ばねを 38 → 26 ドットに ちぢめ、頭（頭楯）を 18×11 → 19×15 に 大きく。頭の はば ≒ 前ばねの はばの 7割
- 太陽の 円盤と 三日月の 角（見せ所）は 元の 大きさの まま。円盤の 柄は 頭に 食いこませて つなぐ
- 足は 6本とも 前ばねの すその 下から 見える 長さに（付け根は すその 下に 重ねる）
- 目は **複眼**（D）：トルコ石色の 横長の ドーム（明・中・暗）に まばらな 六角の 点、後ろがわに たての 白い 反射の 帯。瞳なし。前へ 下がる 太い まゆの 線で 怒りを 出す
- はなれているのは 意図的：砂の 大玉・砂けむり・つむじ（攻撃の エフェクト）

## 色（GBA風・16色以内 → 11色）
輪郭 2（黒／こげ茶）・砂金 3・太陽 3・トルコ石 2・白（つや・歯）

## 動き
- 待機：円盤の 光の とげが ゆらぎ（2通りの 向き）、体が 呼吸で 上下
- 歩き：足を 2組 交互に 動かし、胴が はずむ
- 攻撃：身を ふせ 円盤が 白く 燃える（目も 光り、砂が 舞う）→ かためた 砂の 大玉を 頭の 刃で 押し出す → 大玉が 転がり 砂けむりが 立つ
- 被弾：頭を すくめて 後ろへ さがる
- ダウン：あおむけに ひっくり 返る（目は ×）

## ゲーム上の 目安
- 防御・攻撃が 高め・素早さは 低め
- 技の 例：すなだまころがし（じめん）、たいようえんばん（光を ためて 次の 技を 強化）、すなかき（むし・相手の 命中 ダウン）
