# デンシャコ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | でんき ／ かくとう |
| もとの 生き物 | シャコ（モンハナシャコ） |
| 分類 | でんげきけんとう モンスター（第1形態・約57×53） |
| 性格 | けんかっ早く、目に 入った ものは 何でも なぐって ためす。こぶしの 音で なわばりを 主張する |
| すみか | 岩の すき間の 巣あな。落雷の 多い 浅い 海 |

## 見た目
- 青緑の よろいの かぶと頭。前に とがった 鼻先の 板、口には するどい 牙が 並ぶ
- 頭の 上の 盛り上がり（シャコの 目の 台）に 金色の つり目。厚い まゆ板で かこむ
- 後ろへ 2本の 触角（先に だいだいの 鱗片）
- 胴は 小さく 丸い 胸＋地面に ふせる 節の 腹、だいだいの 尾扇
- **電気を おびた 金の こぶし**（捕脚の こぶ）。手首に かくとう家の テープ
- **デフォルメ（2〜3頭身）**：頭は 全体の 約45%。胸は 丸く 小さく、脚は 短く 太い 2本に まとめた

## 足した もの／引いた もの
- 足した：ボクシングの こぶし（グローブの 指の みぞ・手首の テープ）、こぶしの 火花
- 引いた：細い 歩脚 6本 → 短い 2本、目の 柄 2本 → 頭の 台に うめた 目 1つ（横向き）、腹の 細かい とげ

## まぜた もの と 似ている 点
- シャコの 捕脚の こぶ ⇔ ボクシングの こぶし：どちらも「腕の 先の 丸い 打撃部で 一撃で なぐる」

## 見せ所
- 金の こぶし。頭の 高さの 約3/4 ある 大きな 丸。攻撃では 前へ 打ち出し、稲妻が 走る

## 色（GBA風・16色以内 → 15色）
輪郭 2（黒／濃い紺）・甲羅 3（青緑）・脚と 尾扇 3（だいだい）・こぶしと 目 3（金）・白・電気の 水色・テープの 灰・口の 中の 赤

## 目
白い 光 ＋ 金の 虹彩（明・暗）＋ たての ひとみ。上を 厚い まゆ板、下を まぶたの 線で かこむ。まばたき＝線、被弾＝ゆがんだ 線、ダウン＝×

## 動き
- 待機：胸と 頭が 1ドット 上下、こぶしの 上で 火花が はじける
- 歩き：短い 脚を 交互に、頭が 弾む
- 攻撃：こぶしを 後ろへ 引いて ため → 前へ 打ち出し 口を 開けて 稲妻 → ふりぬき
- 被弾：頭と こぶしが 後ろへ のけぞる
- ダウン：ひっくり 返る（目は ×）

## はなれている もの（意図的）
- 攻撃コマ（atk1／atk2）の 稲妻は 前へ 飛ぶ エフェクト。待機の 火花は こぶしに ふれている

## ゲーム上の 目安
- 攻撃が とても 高い・素早さ 高め・防御 ふつう
- 技の 例：らいげきパンチ（でんき）、いっせんストレート（かくとう）、からわり（防御を 下げる）
