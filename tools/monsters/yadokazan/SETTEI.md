# ヤドカザン（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | ほのお ／ いわ |
| もとの 生き物 | ヤドカリ |
| 分類 | かざんやど モンスター（約61×56） |
| 性格 | 短気で 欲ばり。気に入った 火山を 見つけると 力ずくで 背負い、まわりの 者を 巨大な はさみで 追いはらう |
| すみか | 活火山の ふもとの 溶岩だまり。冷えた 噴石の 円すいを 選んで 貝に する |

## 見た目
- 背中の 貝は 小さな 火山（円すい）。火口から 噴煙が 立ち、らせんの 段の すき間を 溶岩が 流れ落ちる
- カニの 頭は 大きく 丸い こうら。頭に うめこんだ 短い 柄の 先に、まゆの とげの ついた 溶岩色の つり目
- 口は よこに さけ、上あごの 牙が のぞく
- 右の はさみは 体の 3分の1 ほどの 大きさ。掌は 火山岩の よろいで おおわれ、すき間から 溶岩が 光る。指先は 赤熱
- **デフォルメ（2〜3頭身）**：頭（こうら＋目）は 大きく、胴は 小さく 丸く、脚は 短く 太く。はさみ と 火山（見せ所・混ぜた 形）は 大きい まま
- 目は 白い 光＋溶岩色の 虹彩（明 黄・暗 だいだい）＋たての ひとみ。とげの まゆと 下まぶたで かこむ

## 足した もの／引いた もの
- 足した もの：火山の 円すい（貝の かわり）・噴煙・溶岩の すじ（ほのお／いわ）
- 引いた もの：細い 歩脚（4対 → 見える のは 短い 4本だけ）、触角、こまかい 毛、左の はさみは 小さく 奥へ

## まぜた もの と 似ている 点
- ヤドカリの 巻き貝 ⇔ 火山の 円すい：どちらも「下が 広く、上が とがった 山形で、らせん（層）の 段が ある」。巻き貝の 段を そのまま 溶岩の 流れる 岩の 層に 置きかえた

## 見せ所
- 巨大な 右の はさみ（火山岩の よろい＋赤熱した 指）。攻撃では 大きく 開いて 前へ 突きだし、閉じて 火花を 散らす

## はなれている もの（意図的）
- 攻撃の 火花（atk0・atk2）と 噴火の 火の粉（atk1・atk2）は エフェクトなので 体から はなれている（意図的）
- それ以外の 手足・首・尾・ひれ・翼・角は、どの コマでも 付け根を 体に 2〜3ドット 重ねて つないでいる

## 色（GBA風・16色以内）
輪郭 2（黒／こげ茶）・火山岩 3・溶岩 3（黄・だいだい・赤）・カニの 体 3（赤）・噴煙 2・白（牙・光）

## 動き
- 待機：噴煙が もくもく 形を 変え、溶岩の すじが 明滅。胴が 1ドット 上下
- 歩き：短い 脚を 交互に、胴が はずむ
- 攻撃：はさみを 引いて ため（目が 全開・刃先に 火花）→ 火山が 噴火し、はさみを 大きく 開いて 前へ 突く → 閉じて 火花
- 被弾：頭と はさみが 後ろへ のけぞり、目を ゆがめる
- ダウン：ひっくり返る（目は ×）

## ゲーム上の 目安
- 防御と 攻撃が 高い・素早さは 低い
- 技の 例：かざんばさみ（ほのお）、ふんせきおとし（いわ）、からにこもる（防御アップ）
