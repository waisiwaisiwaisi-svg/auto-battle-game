# ヨミアンコウ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | ゴースト ／ みず |
| もとの 生き物 | チョウチンアンコウ |
| 分類 | たまよせ モンスター（第1形態・約56×43） |
| 性格 | しずかで 気味が 悪い。ちょうちんの 魂の 火で 迷った 魂を さそい よせ、大口で 呑みこむ |
| すみか | 光の ない 深海の 底。沈んだ 船の 墓場を ただよう |

## 見た目
- 青白く 血の 気の ない 丸い 体。ひれは ぼろぼろに やぶれた 膜（ゴーストタイプ）
- 頭の 茎の 先の ちょうちんは 青緑の 魂の 火。体の まわりに 人魂が ただよう
- 目は くぼんだ 黒い 穴の 奥で 霊火の ひとみが 光る（細い つり目）
- 前へ つき出た 受け口。上下から 針の ような 長い 牙が はみ出す。口の 中は 暗い 紫
- わき腹の 側線に 霊火の 点が 並ぶ。まわりに 泡（みずタイプ）

## 色（GBA風・16色以内 → 11色）
輪郭 2（黒／濃い藍）・体 3（青白〜藍）・口の 中（暗い 紫）・牙の 白・霊火 3（白緑・青緑・深緑）・紫（予備）

## 動き
- 待機：体が ゆっくり 浮き沈みし、ちょうちんの 火と 人魂が ゆらめく
- 泳ぎ：尾びれと 胸びれが 交互に ゆれ、体が 上下する。地面から 少し 浮いている
- 攻撃：身を 引いて ちょうちんが 大きく 燃え、目が 全開 → 下あごを 大きく 落として 大口で とびこむ（口から 霊気）→ 口を 閉じながら ふりぬく
- 被弾：うしろへ のけぞり、目が ゆがむ
- ダウン：腹を 上に して ひっくり返る

## ゲーム上の 目安
- 体力と 特殊防御が 高い・素早さは 低い
- 技の 例：たまよせのひ（ゴースト・ねむり）、よみのおおぐち（ゴースト）、しんかいのうず（みず）
