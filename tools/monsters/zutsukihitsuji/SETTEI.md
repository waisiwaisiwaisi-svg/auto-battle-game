# ズツキヒツジ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | かくとう ／ いわ |
| もとの 生き物 | ヒツジ（雄の 大角） |
| 分類 | いしあたま モンスター（約56×48） |
| 性格 | 負けずぎらいで 頑固。目が 合った 相手には かならず 頭突きを いどみ、勝つまで やめない |
| すみか | 切り立った 岩山の がけ。岩を 頭で 割って 角を きたえる |

## 見た目
- 体は もこもこの 羊毛だが、背中から 岩の とげが 3本 つき出る
- 頭は 黒い 顔に 石の かぶと（ひたいの 岩板）。横長の ひとみの 金色の 目で にらむ
- 耳の 横に 岩で できた ねじれ角。段の すじが 入り、らせんを 描く
- 前足には 赤い 布を 巻いた 拳闘の 構え。ひづめは 石

## 色（GBA風・16色以内 → 14色）
輪郭 2（黒／こげ茶）・羊毛 3（白〜生成り）・顔と 足 3（灰紫〜黒）・岩 3（砂岩色）・目 1（金）・布 1（赤）・白

## 動き
- 待機：胴と 頭が 1ドット 上下、にらみつける
- 歩き：短い 足で どっしり 進む
- 攻撃：後ろに 下がって 頭を 低く ため（目が 光る）→ 全身で とびこみ 角で 頭突き、白い 衝撃と 岩の かけら → かけらが 飛び散る
- 被弾：頭を はね 上げて のけぞる
- ダウン：その場に たおれて 頭を 落とす（目は ×）

## ゲーム上の 目安
- 攻撃と 防御が 高い・素早さは 低め
- 技の 例：いわくだきヘッド（いわ／かくとう）、ふみこみ（かくとう）、かたくなる（防御アップ）
