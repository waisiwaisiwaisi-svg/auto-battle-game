# ナグリルー

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 子連れの カンガルーではなく、カンガルーを 「荒野の 拳闘士」に した 怪物。

| 項目 | 内容 |
|---|---|
| タイプ | かくとう |
| もとの 生き物 | カンガルー |
| 分類 | けんとう モンスター（約56×59） |
| 性格 | 負けずぎらいで 礼儀ただしい。気に入った 相手には まず 一礼し、それから 全力で なぐる。勝つたびに ふくろの 石を みがく |
| すみか | 赤い 砂の 荒野。岩山の ふもとで 毎日 岩を なぐって きたえる |

## 見た目
- 細く しまった 筋肉の 体、長い 後ろ足と 大きな 足、地面を ささえる 太い 尾。前の めりの ボクシングの かまえ
- 両手に 赤い 拳闘の グローブ、手首に 鉄の びょうを 打った バンド
- 頭は 長い 鼻づらで、耳は 後ろへ 反って とがる。頭の 上に つんつんの 毛
- 黄色い つり目の 上を 古い 傷あとが ななめに 走る。口の はしから きばが のぞく
- はらの ふくろには 子どもではなく **お守りの 石**

## 色（GBA風・16色以内 → 13色）
輪郭 2（黒／こげ茶）・毛 3・はら 2・グローブ 2・鉄（石）2・黄（目・火花）・白

## 動き
- 待機：胴が 上下し、グローブを 小きざみに 出し入れ（ステップ）
- 歩き：大きな 足で はずむ（胴が 2ドット 上がる）
- 攻撃：上体を 引いて ため（目が 光る）→ 前の 手で 右ストレート、こぶしの 先に 火花 → 後ろの 手で 追い打ち
- 被弾：あごを 打たれて のけぞる
- ダウン：あおむけに たおれる（目は ×）

## ゲーム上の 目安
- 攻撃・素早さが 高い、特攻は ひくい
- 技の 例：ストレート（かくとう・先制）、ワンツー（かくとう・2回 攻撃）、しっぽばね（かくとう・回避アップ）
