# シオガニ

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。浜の かわいい カニではなく、岩礁 そのものを 背おった 「岩を くだく 海の 怪物」に した。目は するどく。

| 項目 | 内容 |
|---|---|
| タイプ | みず ／ いわ |
| もとの 生き物 | カニ |
| 分類 | がんしょうばさみ モンスター（第1形態・約58×42） |
| 性格 | がんこで 動じない。なわばりの 岩場に 近づく ものは 大ばさみで 船の 底ごと たたき 割る |
| すみか | 荒れた 海の 岩礁。満ち潮の あいだは 岩に なりすまして じっと している |

## 見た目
- 甲羅は ごつごつの 灰色の 岩。ひびと フジツボが あり、背中には 赤い サンゴが 3本 生えて いる
- 甲羅の 前の 面に 顔。岩の まゆが 前へ 下がり、その 下で 黄色い つり目が 光る（たての ひとみ）。下に 白い 小さな 牙
- 片方だけ 巨大な 岩の 粉砕ばさみ。上の 指は 太く 長く 先が 下へ 曲がり、内がわに 白い 歯。根もとに サンゴの ふさ
- 足は 深い 海の 青。ひざを 高く 立てて 外へ ひろげ、とがった 足先で 立つ
- 口もとから 泡（あわ）が ぽこぽこ 出る

## 色（GBA風・16色以内 → 14色）
輪郭 2（黒／こい紺）・岩 3・サンゴ 3・体（青）3・泡 1・目（黄）1・白（歯）

## 動き
- 待機：呼吸で 甲羅が 上下し、口から 泡が うかぶ
- 歩き：足を 2組 交互に 動かし、甲羅ごと はずむ
- 攻撃：大ばさみを 頭より 高く ふりあげて ため（目が 全開で 光る）→ 前へ ふり下ろして たたきつけ、波しぶきが 立つ → 岩の かけらが 飛ぶ
- 被弾：甲羅を しずめて 後ろへ さがる
- ダウン：あおむけに ひっくり 返る（目は ×）

## ゲーム上の 目安
- 防御・攻撃が 高い・素早さは 低い
- 技の 例：がんさいクラッシュ（いわ）、しおだまりしぶき（みず）、いわがくれ（防御アップ）
