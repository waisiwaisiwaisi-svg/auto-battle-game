# 目の 種類（120体が 同じ 目に ならないように）

ユーザーの 指摘：「目が 大体 一緒」。全員が「白い ハイライト＋虹彩2色＋たて瞳＋まゆ線」の 同じ 型に なっていた。
これからは 下の **目の 種類（A〜T）** から 1つを 選び、形・瞳・白目・大きさ・まわりの 模様で 描き分ける。

## 共通ルール（STYLE.md の 目の ルールも 守る）
- 目は 1色で 描かない（3色以上）。するどさ は 残す（つぶらな だけの 目は ×。S は 太い 眉で 怖く）
- **同じ 種類どうしでも** 色・大きさ・まぶたの 角度 を 変える
- 虹彩の 色は 体の 色と ちがう 色に して 目立たせる
- blink／hit／atk／ko の 差しかえも その 種類に 合わせる（複眼の まばたきは 眉を 下げる、光る目の 被弾は 光が 割れる、など）
- mon.py に `EYE_BOX = (x, y, w, h)` を 書く（idle0 の 64×64 座標で 目の 位置。複数の 目なら 全部を かこむ）。`python3 tools/monsters/_lib/eyes.py out.png` で 全員の 目を 並べて 見くらべる

| M | 重い まぶた（半目） | 上まぶたが 虹彩の 上半分を おおう。冷たく 見下す 目つき | カメ・カバ・ゾウ・シカ・ドクエイ |
| N | 多眼 | 小さな 目が 2〜8個。大きさを 変えて 並べる | クモ・サソリ・ミミズ・アリジゴク |
| O | 傷の目 | 片目に 傷の 線が 縦に 走り、まぶたが 切れている。もう片方は ふつう | 歴戦の 戦士 |
| P | 星・十字の 瞳 | 瞳が 十字・星・輪の 形。虹彩は 多色（グラデーション） | エスパー・フェアリー |
| R | 柄の 先の 目 | 柄（短い 棒）の 先に 丸い 目玉。瞳は 横長か 帯模様 | カニ・ヤドカリ・シャコ |
| S | ビーズ目 ＋ 太い 眉 | 小さく 黒い つぶらな 目に 強い ハイライト 1点、その上に 太く 傾いた 眉で 怖く する | 小さい 目の 生き物（ハリネズミ・ナマズ・ビーバー） |
| T | 出目（飛び出た 目玉） | 顔から 飛び出た 丸い 目玉。まわりに まぶたの 輪、瞳は 小さく 鋭い | カメレオン・獅子舞の 面 |
