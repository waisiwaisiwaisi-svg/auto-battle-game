# マクラン

| 項目 | 内容 |
|---|---|
| タイプ | ノーマル／エスパー |
| もとの もの | まくら（無機物） |
| 分類 | ねむりモンスター（M、約48×37） |
| 性格 | いつも ねむそう で おっとり。じゃまされると 目を ぱっちり 開き、ねむけの 念波で 相手を 眠らせる |
| すみか | 子ども部屋・旅館の 押し入れ・ふとん干しの ベランダ。夜に なると 枕元へ やってくる |

## 見た目
- ふかふかに ふくらんだ 白い 綿の まくら。4すみが つままれて 「耳」の ように とがる。カバーの ふちに 水色の **パイピング**
- 顔は 正面の 右寄り（3/4 右向き）。**ねむそうな 半目**：まるい まぶた（布の 色）が 上半分を おおい、下に 紫の ひとみ（暗い 紫→明るい 紫、白い 光 1点）。手前の 目じりに まつげ。小さな 「o」の 口、大きめの ピンクの ほっぺ
- 左下に 紫の **三日月の 刺しゅう**（エスパーの しるし）、頭の 上に 紫の 「Z」が 浮かぶ（はなれているのは 意図的）
- 下に ちょこんと した 布の こぶの 足 2つ

## 足した もの／引いた もの
- 足した もの：ねむそうな 顔、三日月の 刺しゅう、こぶの 足、Z と 念波の エフェクト
- 引いた もの：まくらカバーの ボタンや タグ、細かい しわ（すみの しわ 4本 だけ 残す）

## まぜた もの と 似ている 点
- まくら の 「ねむり」 ⇔ エスパーの 催眠術（ぐるぐるの 目と 念波）
- まくら投げ ⇔ 体当たり（ため で つぶれて、決めで はずむ）

## 見せ所
- ふだんの とろんと した 半目と、攻撃で 一変する **うずまき（同心円）の 催眠の 目**

## 色（12色）
- 綿の 布 3段（あたたかい 白〜うす紫〜青紫の 影）・パイピング 2段（水色・青）・念波の 紫 2段・目の 黒・白い 光・ほっぺの ピンク・輪郭の 黒と 濃い紫

## 動き
- 待機：体が ふかっと 1ドット 沈む、Z が ゆっくり 上って 2つに ふえる
- まばたき：半目が 「︶」に 閉じて すやすや顔
- 歩く：こぶの 足を 交互に ちょこちょこ、体が 1ドット はずむ
- 攻撃：ため＝体を ぺしゃんこに つぶし（横に 広がる）、まゆが つり上がって きりっと した 目、まわりに 紫の きらめき → 決め＝縦に ふくらんで 前へ はずみ、目が ぐるぐるの 催眠の 目に。紫の 念波（同心の 弧）が 飛ぶ → ふりぬき＝念波が 大きく ひろがる
- 被弾：細く ちぢんで 横に よろけ、目は 「> <」
- ダウン：ぺたんこに つぶれて 横たわり、目は ×。Z が 1つ 残る

## ゲーム上の 目安
- HP・とくぼう 高め、こうげき 低め。念波で ねむり状態を ねらう 妨害役
