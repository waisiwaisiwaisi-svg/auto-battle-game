# ヨイマント（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。コウモリを 「霊火の マントを まとう 夜の 魔物」に した 怪物。目は するどく。

| 項目 | 内容 |
|---|---|
| タイプ | あく ／ ゴースト |
| もとの 生き物 | コウモリの 魔物 |
| 分類 | よいやみマント モンスター（約52×56） |
| 性格 | 残酷で 芝居がかった ふるまいを 好む。マントで 身を つつんで 闇に まぎれ、ひらいた 瞬間に 霊火の さけびで おそう |
| すみか | 打ちすてられた 古い 時計塔や 墓地の 礼拝堂。昼は 天井から さかさまに ぶら下がる |

## 見た目
- **デフォルメ（2〜3頭身）**：頭を 大きく 描きなおし（たて 16＋耳）、胴は 小さく 丸く、足の かぎ爪は 胴に 食いこませて 見せる。翼の マントは 見せ所なので 大きい まま
- 目は 三白眼：太い まゆの 下、白目が 大きく、小さな 赤い 瞳（赤／暗い 赤／芯）が 上の 前に 寄って にらむ。下まぶたの 線は 太く 濃く、その 下に 影の しわ
- 攻撃の 霊火の さけび（音の 輪）と 鬼火は エフェクトなので はなれているのは 意図的
- 二本の 長い とがった 耳（内がわは 深紅）。耳の あいだに とがった 毛
- 太い まゆの 下で 赤い 小さな 瞳で にらむ 三白眼。深紅の 鼻、しかめた 口から 長い 白い 牙
- 翼は マントの ような コウモリの 翼。外がわは 闇色、内がわは 深紅。指の 骨の あいだの 膜は ぼろぼろに えぐれ、すその 先が 青白い 霊火に なって 燃える（ゴーストの しるし）
- 胸に 霊火の 紋。足は 小さな かぎ爪（さかさまに ぶら下がる ため）

## 色（GBA風・16色以内 → 13色）
輪郭 2（黒／こい むらさき）・毛と マントの 外 3（闇むらさき）・マントの 内 3（深紅）・霊火 3（青白〜青緑）・白（牙・白目）・白目の 影 1

## 動き
- 待機：翼を 広げて 浮かび、すその 霊火が ゆらぐ
- 歩き：大きく 羽ばたく（上→中→下→中）
- 攻撃：翼の マントで 体を つつみこみ、白目を むいて 見開く（ため）→ マントを ばっと ひらいて 深紅の 内がわを 見せ、口を 大きく 開けて 霊火の さけび（音の 輪）と 鬼火を 放つ（決め）→ 輪が 前へ ひろがる
- 被弾：翼を はね上げて のけぞる
- ダウン：さかさまに 落ちる（目は ×）

## ゲーム上の 目安
- 特攻と 素早さが 高い・物理防御は 低い
- 技の 例：よいやみのさけび（ゴースト・ひるませる）、マントがくれ（あく・回避アップ）、きゅうけつのきば（あく・HPを すう）
