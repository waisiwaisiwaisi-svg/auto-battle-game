# ハニワシ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | じめん ／ ゴースト |
| もとの 生き物 | ワシ |
| 分類 | はにわ モンスター（約58×55） |
| 性格 | 古い 墓を 守る 番人。墓を 荒らす 者を どこまでも 追い、うつろな 目で にらみつける |
| すみか | 古墳の 丘。土の 中で ねむり、満月の 夜に 目の 穴が 光って 動きだす |

## 見た目
- 全身が 素焼きの 土（はにわ）。ところどころの ひびから 霊の みどりの 光が もれる
- 目は はにわの くりぬき穴。前へ 下がる ななめの 穴の 奥に、霊の 光が 小さく ともる（ワシの 目の 黒い ふちを 兼ねる）
- 大きな かぎ形の くちばし。頭に とがった 冠の 羽
- 翼は 土の 板を 重ねた 羽根。大きく 上へ ひろげる。胸に はにわの 丸い 穴
- **デフォルメ（2〜3頭身）**：頭と くちばしを 大きく、胴は 小さく 丸く、足は 短く。うつろに 光る 目（見せ所）は 大きく
- 目は うつろな 穴の目（I型）：瞳も 白目も ない 暗い 穴。奥は 2段の 影（上は 濃い むらさきの 闇、下の 奥は 土の 底の 暗い 茶）で、その 奥に 霊の 光が 2〜3ドット（白い 芯＋みどり）。ためでは 光が 十字に ふくらみ、被弾は 光が 割れて 散り、ダウンは 光が ×に なる

## 足した もの／引いた もの
- 足した もの：はにわの 穴（目・胸）・土の ひび と 霊の 光（じめん／ゴースト）
- 引いた もの：羽根の 1枚ずつの 線（板 3段に まとめた）、足の うろこ、尾羽の 本数

## まぜた もの と 似ている 点
- はにわの 穴の 目・口 ⇔ ワシの 顔の 黒い ふち：どちらも「目の まわりが 暗く くぼんで 見える」。ワシの 目の まわりの 黒い 筋を、はにわの くりぬいた 穴に 置きかえた

## 見せ所
- うつろに 光る 穴の 目。穴の 奥で 霊の 光が 小さく ともり、攻撃では 十字に 燃え あがる

## はなれている もの（意図的）
- 霊火の つぶ（待機・移動）と 攻撃の 霊の 波（atk1・atk2）は エフェクトなので はなれている（意図的）
- それ以外の 手足・首・尾・ひれ・翼・角は、どの コマでも 付け根を 体に 2〜3ドット 重ねて つないでいる

## 色（GBA風・16色以内）
輪郭 2（黒／こげ茶）・土 3・くちばし 2・霊の 光 3（白・みどり・濃い みどり）・穴の 中（濃い むらさき）・白

## 動き
- 待機：翼を 上下に ゆらし、胴が 1ドット 上下。霊火の つぶが 浮く
- 歩き：短い 足を 交互に、翼を はばたく
- 攻撃：身を ふせて 翼を あげ ため（目が 全開）→ くちばしを 開けて 霊の 波を 放つ → 波が のびる
- 被弾：頭を 後ろへ そらし、目の 光が ゆがむ
- ダウン：ひっくり返る（目の 光は ×）

## ゲーム上の 目安
- 防御と 特防が 高い・素早さは ふつう
- 技の 例：うつろのまなざし（ゴースト・相手を ひるませる）、はにわおとし（じめん）、つちのつばさ
