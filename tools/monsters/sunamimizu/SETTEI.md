# スナミミズ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | じめん |
| もとの 生き物 | 巨大ミミズ |
| 分類 | すなもぐり モンスター（第1形態・約61×56） |
| 性格 | 地面の ゆれだけで 獲物を 見つけ、真下から 砂ごと 丸のみに する。いちど 口を 開けたら 止まらない |
| すみか | 砂漠の 砂の 海。砂山が 動いたら この モンスターが いる 合図 |

## 見た目
- 砂岩の よろいの 節が つらなる 太い 体。腹がわは 赤い 肉
- 砂山から 体を 弓なりに 持ち上げ、右へ 口を 向ける
- 頭は まるい 口だけ。口の 中に 外と 内の 二重の 牙の 輪、のどの 奥は 真っ黒
- 口の ふちの よろいに 三つの 細い 目が たてに 並んで 光る。ふちには 岩の とげ
- 体から 砂が こぼれ 落ちる（じめんタイプ）

## 色（GBA風・16色以内 → 14色）
輪郭 2（黒／こげ茶）・砂岩 3・肉 3・口の 中（暗い 赤）・牙 2（白・骨色）・砂 2・目（だいだい）

## 動き
- 待機：首が 1ドット ずつ 上下し、体から 砂が こぼれる
- 移動：体の 3つの 区切りが 左右に ずれて うねる（砂山は 動かない）
- 攻撃：身を 引いて 三つの 目が 全開 → 口を 大きく 開いて 前下へ のしかかる（砂が はじける）→ 口を 開いたまま ふりぬく
- 被弾：頭が うしろへ そり、目が ゆがむ
- ダウン：砂の 上に 長々と たおれる（目は 消える）

## ゲーム上の 目安
- 体力と 攻撃が 高い・素早さは 低い
- 技の 例：すなのみ（じめん・つかまえる）、じしんもぐり（じめん）、すなあらし（命中ダウン）
