# スナジゴク

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | じめん ／ むし |
| もとの 生き物 | アリジゴク（ウスバカゲロウの 幼虫） |
| 分類 | すりばち モンスター（約62×35） |
| 性格 | がまん強く ずる賢い。砂の すり鉢の 底で 何日も 待ち、落ちて きた 相手を 大あごで はさんで 砂に 引きこむ |
| すみか | 乾いた 砂地や 古い 寺の 縁の 下。すり鉢の 巣を いくつも 持つ |

## 見た目
- **デフォルメ（2〜3頭身）**：平たい 頭は 大きめ（大あごを ふくめ 全体の 約43%）、胸は 小さく 丸く、脚は 短く 太い 3本。腹は 丸く ふくらむ
- 砂色の 体。腹には ふしの 弧の すじと 背中の 剛毛
- 頭の 前から 上下に 2本の **巨大な 大あご**。赤茶の かたい 鎌で、すり鉢の ふちと 同じ 内向きの 弧を えがき、内がわに 白い 歯
- 足もとは 砂の すり鉢（両はしが 高く、まん中が くぼむ）
- 目：多眼（N）。頭の 上に 大きさの ちがう 小さな 目が 4つ（前の 大きい 目・後ろの 小さい 目・下に 中くらいの 2つ）。どれも 黄〜だいだいの 玉に 白い 光、前の 大きい 目の 上に 前へ 下がる 殻の ふち（まばたき＝全部 線、被弾＝ばらばらに つぶる、ダウン＝4つとも ×）
- 大あごは 頭に、頭と 脚は 胸に、胸は 腹に 2〜3ドット 食いこませて つなぐ

## 足した もの／引いた もの
- 足した もの：すり鉢の 砂の 足場、大あごの 歯
- 引いた もの：脚 6本 → 3本、体の 細かい 毛（背中の 剛毛 数本だけ）

## まぜた もの と 似ている 点
- アリジゴクの 大あご ⇔ すり鉢の ふち：どちらも **内向きの 弧で 獲物を 中へ 閉じこめる 形**。大あごの 弧と 足もとの すり鉢の 弧を そろえた

## 見せ所
- 頭の 前に 大きく ひらく **2本の 大あご**（頭と 同じ くらいの 長さ）。攻撃で 大きく ひらき、ばちんと とじる

## はなれて いる もの（意図的）
- 攻撃の 砂しぶき（atk1・atk2）は エフェクト。ダウンでは 体が すり鉢の 上に ひっくり返る

## 色（GBA風・16色以内 → 13色）
輪郭 2（黒／こい茶）・体 3・大あご 3・砂 2・目 2（黄／だいだい）・白

## 動き
- 待機：腹が ふくらんで しぼむ
- 歩き：短い 脚を 交互に、頭が 上下
- 攻撃：頭を 引いて 大あごを 大きく ひらく（4つの 目に 光が ふえる）→ 前へ とびこみ 大あごを ばちんと とじる、砂が 飛ぶ → ふりぬき
- 被弾：頭が 後ろへ のけぞり、大あごが ひらく
- ダウン：あおむけに ひっくり返る（脚が 上、目は ×）

## ゲーム上の 目安
- 攻撃と 防御が 高い。素早さは 低い
- 技の 例：おおあごばさみ（むし）、ありじごく（じめん・にげられなく する）、すなかけ（命中ダウン）
