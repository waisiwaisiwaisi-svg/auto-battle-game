# テツビンガメ

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | はがね ／ ほのお |
| もとの 生き物 | カメ（ワニガメ） |
| 分類 | てつびん モンスター（約56×40） |
| 性格 | がまん強いが、おこると 甲羅の 底が 赤く 焼け、熱い 湯気を ふき出す |
| すみか | 温泉地の 火山の ふもと。熱い 岩の 上で 甲羅を あたためる |

## 見た目
- **デフォルメ（2〜3頭身）**：大きな 頭（全体の 約4割）、甲羅は 丸く ずんぐり、足は 短く 太い
- 甲羅は **鉄瓶**：あられ（鉄の つぶ）の もよう、上に ふたと つまみ、大きな つる（とって）が 甲羅の 上を アーチで こえる
- 甲羅の 底の ふちは 熱で 赤く 光る。ふたの つまみから 湯気が 立つ（つまみに つながって いる）
- 首は 鉄瓶の **注ぎ口**：鉄の 筒が 前へ のび、その 先から 頭が 出る
- 頭は ワニガメの ような かぎ形の くちばし、後ろへ 反る とげ、ほおに 熱い ひび。目は 白い 光＋黄・だいだい の 虹彩＋ひとみ、まゆの 線
- 攻撃の 炎と 湯気の 息は エフェクトなので **はなれて いるのは 意図的**

## 足した もの／引いた もの
- 足した もの：鉄瓶の ふた・つまみ・つる、注ぎ口の 首、湯気。
- 引いた もの：甲羅の 板の 区切り（あられ もように まとめる）、指の 数

## まぜた もの と 似ている 点
- カメの 甲羅 ⇔ 鉄瓶（どちらも 丸い ドームの 器）。首 ⇔ 注ぎ口（器から 前へ のびる 筒）。つるは 甲羅の 上で 弧を えがく

## 見せ所
- つるつきの 鉄瓶の 甲羅（体の 大部分）

## 色（GBA風・16色以内）
14色：輪郭 2（黒／こげ茶）・鉄 3・熱の 3（黄・だいだい・赤）・皮 3（赤茶）・湯気 2・白

## 動き
- 待機：甲羅の 底が 明滅、つまみの 湯気が ゆれる
- 歩き：短い 足で 重く 進む
- 攻撃：首を 甲羅に 引いて ため（目が 光る）→ 首を のばし 口を 開け 炎と 湯気を ふく → 湯気が ひろがる
- 被弾：首を すくめる
- ダウン：ひっくり 返る（目は ×）

## ゲーム上の 目安
- 防御と 体力が 高い。素早さは ひくい
- 技の 例：ねっとうブレス（ほのお・やけど）、てっぴのまもり（はがね・防御アップ）、かみくだく
