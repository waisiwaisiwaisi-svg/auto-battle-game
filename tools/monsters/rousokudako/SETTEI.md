# ロウソクダコ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | ゴースト ／ ほのお |
| もとの 生き物 | タコ |
| 分類 | しょくだい モンスター（約54×57） |
| 性格 | 陰気で 執念深い。霊火に 誘われて 近づいた 者に ろうの 足を からめ、熱い ろうで 固めてしまう |
| すみか | 沈んだ 寺や 灯台の 跡。暗い 海の 底で 青い 霊火を ともしている |

## 見た目
- 頭（外とう膜）は 白い ろうそくの 本体。上の ふちは 溶けて すじに なって たれ、てっぺんの しんに 青い 霊火が ともる
- 首には 真ちゅうの 燭台の 皿。皿の ふちから ろうが たれる
- 顔は 前に つき出し、霊火色の つり目と 牙の 並ぶ 口
- 足は 6本 見える ろうの 足。太く たれさがり、先は 丸まる。吸盤の 点と 途中に ろうの しずく
- **デフォルメ（2〜3頭身）**：頭（ろうそく）は 大きく、足は 短く 太く。霊火と ろうの 足（見せ所）は 目立つ 大きさ
- 目は 白い 光＋霊火の 虹彩（明 水色・暗 青むらさき）＋たての ひとみ。ろうの まゆで かこむ

## 足した もの／引いた もの
- 足した もの：霊火（ゴースト／ほのお）・燭台の 皿・溶けた ろうの すじ と しずく
- 引いた もの：足を 8本 → 見える 6本に、吸盤は 点だけ、漏斗（ろうと）は 省いた

## まぜた もの と 似ている 点
- タコの 垂れる 足 ⇔ 垂れる ろう：どちらも「上から 下へ たれさがり、先が 丸く ふくらむ」。外とう膜を ろうそく本体に、足を 皿から 流れ落ちた ろうに 置きかえた

## 見せ所
- ろうの 足（太く たれる 6本の 足と しずく）と、頭の 霊火。攻撃では 足を 前へ のばし、霊火の 玉を 飛ばす

## はなれている もの（意図的）
- 霊火の 玉（atk1・atk2）は 飛んでいく 霊火なので はなれている（意図的）。ダウンの 煙も 同じ
- それ以外の 手足・首・尾・ひれ・翼・角は、どの コマでも 付け根を 体に 2〜3ドット 重ねて つないでいる

## 色（GBA風・16色以内）
輪郭 2（黒／濃い むらさき）・ろう 3（白〜むらさき）・真ちゅう 2・霊火 3（白・水色・青むらさき）・炎の しん（だいだい）・口の 中・白

## 動き
- 待機：霊火が ゆらぎ、頭と 足が 交互に 1ドット 上下
- 移動：体ごと 浮き沈みし、足が 交互に うねる
- 攻撃：霊火が 大きく 燃え 上がり（ため）→ 足を 前へ のばして 口を 開け、霊火の 玉を 飛ばす → 玉が 小さく なって 飛んで いく
- 被弾：頭が 後ろへ のけぞり、霊火が かたむく
- ダウン：霊火が 消えて 煙に なり、ひっくり返る（目は ×）

## ゲーム上の 目安
- 特攻と 特防が 高い・素早さは 低い
- 技の 例：れいかのたま（ゴースト）、とけろうしばり（ほのお・相手の 素早さダウン）、ともしびの のろい
