# ヒトクイソウ

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | くさ ／ どく |
| もとの 生き物 | 食虫植物 |
| 分類 | ひとくい モンスター（第1形態・約54×46） |
| 性格 | 動かずに じっと 待つ。毒の あまい においで 獲物を よび、首を のばして ひと口で のみこむ |
| すみか | 湿った 沼地の 森。根を はった 場所から 一生 はなれない |

## 見た目
- **デフォルメ（2〜3頭身）**：頭（さや）を 大きく して 全体の 約4割に、くきは 短く 太く、毒の ふくろは 小さく 丸い まま。くきは 頭と ふくろの 中まで 食いこませる
- 口から 落ちる 毒の しずくと 攻撃の 毒の かたまりは エフェクトなので はなれて いるのは 意図的
- 土の 山に 根を はり、根の つめで 地面を つかむ。根もとに ぎざぎざの 葉が 2枚
- 体は 紫の 毒の ふくろ（球根）。毒が 黄色く 光る 斑点と 黒い すじ
- ふくろの 上から とげの ある 太く 短い くきが のび、先は 横に さける 大きな 種の さやの 頭
- 頭の 後ろに 先が 紫の とがった がくが 扇の ように 開く
- さやの 上に うつろな 穴の 目（目の種類 I）：つり上がった ふちの 中は こい緑→まっ黒の 2段の 影、その 奥に 緑の 光点が 1つ ともる。ふちから ひびの すじ。口の 中は 赤く、とげの 歯が 並び、紫の 毒が したたる

## 色（GBA風・16色以内 → 14色）
輪郭 2（黒／こい緑）・葉と くき 3・毒の ふくろ 3・光る 毒の 黄・目の 緑の 光点と 穴の 闇・口の 赤・白（歯）・土 2

## 動き
- 待機：くきと 頭が ゆらゆら 1ドット ゆれ、口から 毒の しずくが 落ちる
- 歩き（その場で）：根は 動かず、くきと 葉を 左右に ゆらして はうように うごめく
- 攻撃：首を 後ろへ 引いて ため（穴の 奥の 光が 大きく ふくらむ）→ くきを 前へ 長く のばして 口を 大きく 開け、毒の かたまりを はき出す → 口を とじて ふりぬき、毒が 飛ぶ
- 被弾：くきが 後ろへ しなる
- ダウン：くきが しおれて 頭が 地面に たおれる（目は ×）

## ゲーム上の 目安
- 特攻と 体力が 高い。素早さは とても ひくい（動けない）
- 技の 例：どくはき（どく）、くいつき（くさ・体力を すいとる）、あまいにおい（相手を ひきよせる）
