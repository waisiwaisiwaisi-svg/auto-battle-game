# ミツガシラ

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | はがね ／ あく |
| もとの 生き物 | ケルベロス（三つ首の 番犬） |
| 分類 | ばんけん モンスター（最終形態・約55×55） |
| 性格 | 3つの 首が 交代で ねむらずに 見はる。主と みとめた 者いがいは 門に 近づけない |
| すみか | 古い 城の 地下の 鉄の 門。くさりと 鉄くずの 山を ねどこに する |

## 見た目
- **デフォルメ（2〜3頭身）**：3つの 頭を 大きく 描きなおし（1つ たて 18）、扇の ように ずらして 重ねる。胴は 短く 丸く、足は 短く 太い
- 目は 光る目（瞳なし）：3つの 首 すべて、黒い まゆの 下で 赤い 光が 細く 燃える。芯は 白〜うす桃、ふちは 黒線の かわりに 暗い 赤の にじみ。前へ さがる つり形で、光は 後ろへ 尾を 引く
- 奥の 2本の 首は 胴から のびる 首（暗い 色）で つなぐ。攻撃の つめあとは エフェクトなので はなれているのは 意図的
- 短く 丸い 黒鉄色の 犬の 体。背中に 鉄の くら（びょうと とげ 3本）
- 首は 3つ。奥の 首ほど 高く、暗い。どの 首にも とげの ついた 鉄の 首輪
- 耳の 先は 鉄。黒い まゆの 下で 瞳の ない 赤い 光る目が 燃える。口は いつも うなって 牙が のぞく（口の 中は 赤黒い）
- 肩の 上から やみの 火（紫の 炎）が たてがみの ように もえ、しっぽの 先にも やみの 火
- 足は 鉄の すねあて、白い つめ

## 色（GBA風・16色以内 → 14色）
輪郭 2（黒／こい紫）・体 3・鉄 3・目 3（赤の 光／うすもも の 芯／暗い 赤の にじみ＝口の 赤と 共用）・やみの 火 2・口の 赤・白（牙・つめ）

## 動き
- 待機：3つの 首が ばらばらに 1ドット 上下、やみの 火の たてがみと しっぽの 火が ゆらぐ
- 歩き：4本の 足を 交互に、どっしり 進む
- 攻撃：3つの 首を 後ろへ 引いて ため（目の 光が ふくらみ、白い 芯が 広がる）→ 3つの 首が 時間差で とびかかり、口を 大きく 開けて かみつく。前に やみの 火の つめあと → ふりぬき
- 被弾：3つの 首が そろって のけぞる（目の 光が ばらばらに 割れる）
- ダウン：ひっくり 返る（目は 赤い ×）

## ゲーム上の 目安
- 攻撃と 体力が 高い。特殊防御は ひくめ
- 技の 例：みつくびかみ（あく・3回 こうげき）、てっぺきのくび（はがね）、やみのほのお（あく）
