# ハガマ

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 虫ではなく、カマキリを 「葉の 刃で 斬る 狩人」に した 怪物。

| 項目 | 内容 |
|---|---|
| タイプ | くさ ／ むし |
| もとの 生き物 | カマキリ |
| 分類 | はがたな モンスター（約56×59） |
| 性格 | 冷たく しんぼう強い 待ちぶせ型。森の 葉に まぎれて 何時間も 動かず、えものが 間合いに 入った 一瞬で 斬る |
| すみか | 深い 森の しげみ。枯れ木と 若葉の あいだ |

## 見た目
- 太い 足を 前後に 大きく ひらいて ふんばる（ひざは 外へ 張り出す）。胸は 太い 樹皮の よろいで、板の さかい目と 背中の とげ
- 前足の 先は **大きな 葉の 鎌** が 2本。奥の 鎌は 高く ふりあげ、手前の 鎌は 前で かまえる。内がわの ふちに 白い 先の のこぎり歯、まん中に 葉脈
- 腹は 一枚の 大きな 葉の 形。後ろへ のびて 尾の ように ゆれる
- 大きな 三角の 頭。まゆの ひさしの 下で 光る 複眼（たての ひとみ）、口先に 白い 牙の 大あご、前へ のびる 触角、頭の 後ろに 葉の とさか
- 羽は ない（地上で 斬る ことに 特化）

## 色（GBA風・16色以内 → 12色）
輪郭 2（黒／こげ茶）・樹皮 3・葉 3・複眼 3（黄／だいだい／赤）・白（歯）

## 動き
- 待機：胴が 上下、葉の 腹が ゆらゆら ゆれる
- 歩き：細い 足を 交互に、胴が 弾む
- 攻撃：鎌を 後ろへ 引いて ため（複眼が 黄色く 光る）→ 前へ 鎌を ふりぬき 葉の 三日月の 斬撃 → ふりおろして 葉が 舞う
- 被弾：のけぞって 目を ゆがめる
- ダウン：あおむけに たおれる（目は ×）

## ゲーム上の 目安
- 攻撃・素早さが 高い、防御は ひくい
- 技の 例：はがたな（くさ・急所に 当たりやすい）、まちぶせ（むし・先制）、はっぱしぐれ（くさ）
