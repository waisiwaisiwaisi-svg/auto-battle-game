# ヨロイガメ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | いわ ／ みず |
| もとの 生き物 | リクガメ（ワニガメの 頭） |
| 分類 | じょうへき モンスター（第1形態・約64×55） |
| 性格 | 動じない 守りの 主。近づく 者は だれでも 敵と みなし、甲羅の 砲門から 水を 撃つ |
| すみか | 湖の 中の 古い とりで あと。百年 かけて 甲羅に 石を 積み上げた |

## 見た目
- 甲羅は 石を 積んだ 城壁。上には 凸凹の 胸壁と 小さな 塔、ふちには 甲羅の うろこ板
- 壁の あちこちに 矢狭間（たての すき間）。中に たまった 水が 青く 光る。苔が 生えている
- 甲羅の 前に まるい 砲門、うしろの 樋口から 滝が 流れ落ちる
- 頭は ワニガメの ように 平たく、先が かぎ形に 曲がった 石の くちばし
- 黄色い 細い つり目に 重い まゆ。足は 太く しわが 刻まれ、白い つめ

## 色（GBA風・16色以内 → 14色）
輪郭 2（黒／紺黒）・城壁の 石 3・皮 3・水 3・目の 黄・苔・白

## 動き
- 待機：うしろの 滝が 流れつづけ、矢狭間の 水が 明滅
- 歩き：重く 一歩ずつ、甲羅が 上下
- 攻撃：首を 甲羅に 引っこめ 身を 沈める（ため・矢狭間が 光る）→ 甲羅の 砲門から 水の 大砲 → 先で しぶきが はじける
- 被弾：首を 上げて 後ろへ
- ダウン：ひっくり 返る（目は ×）

## ゲーム上の 目安
- 防御が とても 高い・素早さは とても 低い
- 技の 例：じょうへきほう（みず）、ろうじょう（防御アップ）、いしがき おとし（いわ）
