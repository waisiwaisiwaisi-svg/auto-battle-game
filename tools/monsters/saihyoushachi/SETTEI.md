# サイヒョウシャチ

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | みず ／ こおり |
| もとの 生き物 | シャチ |
| 分類 | さいひょうせん モンスター（約60×54） |
| 性格 | 冷静な 狩人。むれの 先頭を 泳ぎ、背びれで 氷の 海を 切りひらいて 道を 作る |
| すみか | 流氷の 海。厚い 氷の 下を まっすぐ 進む |

## 見た目
- 背びれが 砕氷船の 船首の ような 前へ つき出た 鋭い 板。氷の 鉄板で できて いて、つぎ目と 鋲の 列、前の ふち（刃）は 白く 光り、根もとに 赤い 喫水線の 帯と 氷の かけら
- 体は シャチの 黒と 白。目の 後ろ上に 白い アイパッチ、下あごと 腹は 白
- 口には 白い 三角の 歯が 並ぶ。黒い まゆの 下に 金の つり目
- 短く 太い 胸びれ、ふたまたの 尾びれ
- **デフォルメ（2〜3頭身）**：頭を 大きく まるく、胴は 短く した。見せ所の 背びれは 大きい まま
- 目は 白い 光＋金と だいだいの 虹彩＋たての ひとみ、まゆと 下まぶたの 線（黒い はだの 上の 被弾・ダウンの 目は 白い 線で かく）

## 足した もの／引いた もの
- 足した：氷の 鉄板の 船首（こおり）、赤い 喫水線、氷の いぶき
- 引いた：シャチの 長い 胴を 短く、白い もようは アイパッチと 腹 だけに した

## まぜた もの と 似ている 点
- シャチの 背びれ ⇔ 砕氷船の 船首：どちらも「水を 切る とがった 板」。背びれの 形を 前へ 反らせて 船首に した

## 見せ所
- **砕氷船の 背びれ**。攻撃の ときは 刃が 全部 白く 光る

## はなれた パーツ（意図的）
- 攻撃の 氷の いぶき（エフェクト）だけ

## 色（GBA風・16色以内 → 14色）
輪郭 2（黒／こい 紺）・黒 3・白 2（＋純白）・氷 3・赤 1（喫水線・口の 中）・目 2

## 動き
- 待機：体が ゆっくり 上下に うく、尾びれと 胸びれが ゆれる
- 歩き（泳ぎ）：体が 上下に うねり、尾びれが ふれる
- 攻撃：後ろへ 引いて ため（口を 開き 背びれの 刃が 光る）→ 前へ とびこみ 大口を 開けて 氷の いぶき → 氷の かけらが ひろがる
- 被弾：後ろ上へ はじかれ、目は くの字
- ダウン：腹を 上に して うく（目は ×）

## ゲーム上の 目安
- 攻撃・素早さが 高め、HPも 高め
- 技の 例：さいひょうフィン（こおり）、つららのいぶき（こおり）、たいあたり（みず）
