# モンスターの 考え方（第2弾 61〜120 から 使う）

参考：
- hishiwo「モンスターデザインのしかた」 https://tips.clip-studio.com/ja-jp/articles/9499
- いちあっぷ「足し引きで考える、デフォルメモンスターの作り方と考え方」 https://ichi-up.net/2019/70

STYLE.md の ルール（GBA風・16色・14コマ・するどい目）は そのまま。そのうえで、デザインを 次の 手順で 決める。

## 1. もとの 生き物を 1つ 決める
- ほとんどの モンスターには もとに なる 生き物が いる。**シルエットの 大部分は もとの 生き物の まま** にして、何の モンスターか 一目で わかるように する

## 2. 足す・引く（足し引き）
- **足す**：属性を 表す パーツを 1〜2個 だけ 足す（例：ペガサス＝馬＋翼）。足しすぎると 何か わからなく なる
- **引く**：いらない パーツを 減らす・まとめる（脚の 数を 減らす、細かい 模様を けずる）。64ドットでは 引く ほうが 大事
- SETTEI.md に「足した もの／引いた もの」を 書く

## 3. 似た 形どうしを まぜる
- 2つの ものを 合わせる ときは、**形や しくみが 似ている もの** を 選ぶと なじむ
  （例：ハサミと 時計は「とがった 2本が 1つの 軸で つながる」ところが 同じ）
- 「どこが 似ているか」を 1行で 言えること（例：ヤドカリの 巻き貝 ⇔ 火山の 円すい）。その 似た 部分を つなぎ目に して 置きかえる
- SETTEI.md に「まぜた もの と 似ている 点」を 書く

## 4. 見せ所を 誇張し、ほかは 小さく
- そのモンスターの **見せ所（いちばん 目立つ 特徴）を 1つ** 決め、思いきり 大きく する（はさみ・きば・角・口 など）
- 見せ所で ない ところは 小さく・単純に して メリハリを つける
- 頭身と、手足・顔の パーツの 大きさで 印象が 決まる。64×64 では 頭を やや 大きめ、見せ所を 体の 1/3 くらいまで 大きく して よい
- ただし かわいく しない：目は するどく、口・牙・爪で 強さを 出す
- SETTEI.md に「見せ所」を 書く
