# エンジャク（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。燃えつきない 炭の 羽を もつ 猛禽の 怪物。明るい 火の鳥では なく、黒い 炭の 体に 熾火（おきび）が 光る 不吉な 姿に する。

| 項目 | 内容 |
|---|---|
| タイプ | ほのお ／ ひこう（風） |
| もとの 生き物 | 不死鳥（伝説の 火の鳥）＋ 猛禽 |
| 分類 | すみばね モンスター（約60×55） |
| 性格 | 気が あらく、火事の 煙を 見つけると 集まってくる。獲物を 熱風で 追いつめる |
| すみか | 山火事の あとの 焼け野原、火山の 上の 上昇気流 |

## 見た目
- 体と 羽は すすけた 黒紫の 炭色。羽と 胸に 熾火の ひびが 走り、だいだいに 光る
- 頭の 上から 後ろへ、骨の 刃の ような とさか（炎の とさかでは ない）
- くちばしは 白い 骨の かぎ形で、ふちが のこぎりの 歯の ように ぎざぎざ。まゆの 下に 金色の 細い 目
- 翼の 先の 風切り羽が 炎に なって 燃えている。尾は 1本の 長い 火の 帯で、S字に うねる
- 骨色の かぎ爪を 下に たらして 宙に うかぶ

## 色（GBA風・16色以内 → 12色）
輪郭 2（黒／こい赤）・炭の 羽 3・炎 4（白黄・だいだい・赤・こい赤）・骨 2（くちばし・爪・とさか）・白

## 動き
- 待機・歩き（はばたき）：翼を 上 → 横 → 下 → 横 と はばたき、体が 1〜2ドット 上下。尾の 火の 帯が うねる
- まばたき：目が 閉じる
- 攻撃：翼を 高く 上げ 身を 引く（目が 光る）→ 翼を 打ちおろして 炎の つむじ風を 前へ → 横に ひろげて ふりぬく
- 被弾：首を すくめて 後ろへ
- ダウン：地面に 落ちて 首を たれる（目は ×）

## ゲーム上の 目安
- 特攻と 素早さが 高い。防御は 低め
- 技の 例：ねっぷうがえし（ほのお）、すみかぜ（ひこう）、はねやき（ほのお・やけど）
