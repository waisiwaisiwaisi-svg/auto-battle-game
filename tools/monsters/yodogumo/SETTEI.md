# ヨドグモ

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。小さな 家グモではなく、腹に 毒を ためこんだ 「よどみ沼の 狩人」の 怪物に した。目は するどく。

| 項目 | 内容 |
|---|---|
| タイプ | どく ／ むし |
| もとの 生き物 | クモ |
| 分類 | どくだまり モンスター（第1形態・約60×41） |
| 性格 | 気が 長く ずるがしこい。えものが 弱るまで 遠くから 毒を 浴びせ、最後に 牙で しとめる |
| すみか | 毒の わく よどんだ 沼の ほとり。枯れ木の あいだに 巣を はる |

## 見た目
- 体は よどんだ 紫。大きく ふくらんだ 腹に 毒の ふくろが 5つ すけて 見え、黄緑に 光る
- 頭胸部の 前に 赤い 目が 8つ。大きな 2つは 重い まゆの 下の つり目、上に 小さな 目が ならぶ
- 骨色の 太い 牙が 下へ 曲がり、先から 毒の しずくが たれる
- 長い 足が 8本。ひざを 高く 立てて 体を つりさげる ように 立つ。ひざの 上に とげ毛

## 色（GBA風・16色以内 → 12色）
輪郭 2（黒／こい紫）・体 3・毒 3・目（赤）・牙 2・白（目の 光）

## 動き
- 待機：腹の 毒ぶくろが 明滅し、牙の 先から しずくが 落ちる
- 歩き：足を 2組 交互に 動かし、胴が はずむ
- 攻撃：頭を もたげ 前足を ふりあげ 牙を ひらく（目が 全開）→ 前へ とびこみ 毒の かたまりを 吐く → 毒が はじけて 飛びちる
- 被弾：頭を さげて 後ろへ さがる
- ダウン：あおむけに ひっくり 返り 足を ちぢめる（目は ×）

## ゲーム上の 目安
- 特攻・素早さが 高め・防御は 低め
- 技の 例：よどみどく（どく）、どくきば（どく）、しばりいと（むし・相手の 素早さ ダウン）
