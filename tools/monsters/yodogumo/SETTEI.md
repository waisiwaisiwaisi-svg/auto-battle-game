# ヨドグモ

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。小さな 家グモではなく、腹に 毒を ためこんだ 「よどみ沼の 狩人」の 怪物に した。目は するどく。

| 項目 | 内容 |
|---|---|
| タイプ | どく ／ むし |
| もとの 生き物 | クモ |
| 分類 | どくだまり モンスター（第1形態・約59×34・デフォルメ） |
| 性格 | 気が 長く ずるがしこい。えものが 弱るまで 遠くから 毒を 浴びせ、最後に 牙で しとめる |
| すみか | 毒の わく よどんだ 沼の ほとり。枯れ木の あいだに 巣を はる |

## 見た目
- **デフォルメ**：頭胸部（顔）は 元の 大きさの まま、腹を 頭と 同じ くらいに 小さく し、足は 短く 2ドットの 太さに した。ひざは 体の 外に 出して 見せる。奥の 足は 2本だけ 見せる（引く）
- 目は **多眼**（N）：赤い 目が 8つ、大きさを 変えて ならぶ（大 2つ＝つやの 白＋赤 2色・中 1つ・小 5つ）。たての ひとみは なく、つやの ある 玉
- 足の 付け根は 頭胸部の 下に かくして つなぐ。毒の しずく・毒だまは エフェクト
- 体は よどんだ 紫。まるく ふくらんだ 腹に 毒の ふくろが 5つ すけて 見え、黄緑に 光る
- 頭胸部の 前に 赤い 目が 8つ。前の 低い ところに 大きな 2つ、後ろに 中 1つ、上に 小さな 目が ならぶ
- 骨色の 太い 牙が 下へ 曲がり、先から 毒の しずくが たれる
- 太く 短い 足が 8本（見えるのは 6本）。ひざを 立てて 体を つりさげる ように 立つ。ひざの 上に とげ毛

## 色（GBA風・16色以内 → 13色）
輪郭 2（黒／こい紫）・体 3・毒 3・目 2（赤・暗い 赤）・牙 2・白（目の 光）

## 動き
- 待機：腹の 毒ぶくろが 明滅し、牙の 先から しずくが 落ちる
- 歩き：足を 2組 交互に 動かし、胴が はずむ
- 攻撃：頭を もたげ 前足を ふりあげ 牙を ひらく（目が 全開）→ 前へ とびこみ 毒の かたまりを 吐く → 毒が はじけて 飛びちる
- 被弾：頭を さげて 後ろへ さがる
- ダウン：あおむけに ひっくり 返り 足を ちぢめる（目は ×）

## ゲーム上の 目安
- 特攻・素早さが 高め・防御は 低め
- 技の 例：よどみどく（どく）、どくきば（どく）、しばりいと（むし・相手の 素早さ ダウン）
