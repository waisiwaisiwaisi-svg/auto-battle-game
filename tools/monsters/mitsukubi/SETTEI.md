# ミツクビ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | ドラゴン ／ どく |
| もとの 生き物 | ヒドラ（多頭の 竜） |
| 分類 | さんとうどくりゅう モンスター（第1形態・約62×57） |
| 性格 | 三つの 首が それぞれ 別の 敵を ねらう。うしろの 首は 見はり役で、いつも 周りを にらんでいる |
| すみか | 毒の 霧が たちこめる 湿地の 底。毒の 沼の 水を のんで 毒を ためる |

## 見た目
- 四つ足の 重い 胴から 長い 首が 三本。上・まん中・下と 高さを ずらして 前を 向く
- うろこは 濃い 紅色、首と 腹の 前側は クリーム色の 段の ある 腹板
- 頭は 平たい 竜の 頭、後ろに 小さな とげ。黄緑に 光る 細い 目
- 口の 中は 毒の 黄緑。口の 端から 毒の よだれが たれる
- 背骨に そって むらさきの とげ

## 色（GBA風・16色以内 → 13色）
輪郭 2（黒／赤黒）・うろこ 3・腹 2・毒 3・背の とげ 2・白

## 動き
- 待機：三つの 首が ばらばらに ゆれ、口から 毒の しずく
- 歩き：胴を ゆすって のし歩き、首が 交互に 上下
- 攻撃：三つの 首を そろって 後ろへ 引く（ため・目が 白く 光る）→ いっせいに 前へ のばして 口を 開け、毒の かたまりを 吐く → 毒が はじけ 散る
- 被弾：首が そり返る
- ダウン：ひっくり 返る（目は ×）

## ゲーム上の 目安
- 攻撃回数が 多い（3回 かみつき）・HP 高め・素早さ ふつう
- 技の 例：トリプルバイト（ドラゴン）、どくだまの 雨（どく）、もうどくの よだれ（どく・もうどく）
