# ノリムスビ

| 項目 | 内容 |
|---|---|
| タイプ | くさ／じめん |
| もとの もの | おにぎり（無機物） |
| 分類 | おむすびモンスター（S、約46×46） |
| 性格 | のんびり 屋で 人なつっこい。てっぺんの 梅干しが すっぱく なると 本気を 出す |
| すみか | 田んぼの あぜ道・山の 畑の 小屋。ころがって 土まみれに なる |

## 見た目
- 角の 丸い 三角の ごはん（右へ 少し かたむいた 3/4）、下の まん中に 海苔の 帯。てっぺんに しわしわの **梅干し**、梅干しから **しその 葉** が 1枚 生える
- 顔は 海苔の 上の ごはんの 面。**つぶらな 点の 目**（白い 光・こげ茶の 黒目・下に 海苔色）＋ ピンクの ほっぺ ＋ 赤い 舌の 見える 口
- 左右に ごはんの 小さな 手、下に ちょこんと 足。左下に ころがった 土の よごれ

## 足した もの／引いた もの
- 足した もの：顔、ごはんの 手足、梅干しの しそ（くさ）、土の よごれ（じめん）
- 引いた もの：ごはんつぶ 1粒ずつの 輪郭（2ドットの つぶ もように まとめた）、海苔の 細かい しわ

## まぜた もの と 似ている 点
- おにぎりの 三角 ⇔ ずんぐりした 体。梅干し ⇔ 頭の かざり（元気の もと）

## 見せ所
- 海苔の 帯 ＋ 梅干しと しその 葉の 3色の シルエット。攻撃で しその 葉が 回る 刃に なって 飛ぶ

## 色（16色）
- ごはん 3段（黄みの 白→灰茶）・海苔 3段（緑の 黒）・梅干し 3段・しそ 2段・黒・こげ茶（輪郭／土）・白・ほっぺの ピンク・目の 黒

## 動き
- 待機：体が 1ドット 上下、しその 葉が ゆれる
- 歩く：足を 交互に 上げて ぴょこぴょこ はねる
- 攻撃：まゆを つり上げ 身を ふせて 手を 上げる（ため）→ 前へ とびこみ、口を 大きく 開けて しその 葉の 刃と 土くれを 飛ばす
- 被弾：うしろへ よろけ、目が「＞＜」
- ダウン：横だおしに なり、梅干しと しそが ころがり 落ちる。目は ×。土ぼこり
- はなれている もの（しその 刃・土くれ・ころがった 梅干し）は エフェクトで 意図的

## ゲーム上の 目安
- ぼうぎょ・HP 高め、すばやさ 低め。しその 刃と 土くれで けずる ねばり強い 前衛
