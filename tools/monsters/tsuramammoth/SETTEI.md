# ツラマンモス（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | こおり ／ いわ |
| もとの 生き物 | マンモス |
| 分類 | ひょうが モンスター（第1形態・約61×43） |
| 性格 | 無口で がんこ。群れを 守る ためなら 吹雪の 中でも 一歩も ひかず、きばで 押し返す |
| すみか | 永久凍土の 雪原。背の 氷河の 岩は 何百年も かけて 育った もの |

## 見た目
- こげ茶の 長い 毛の マンモス。すその 毛は ぼさぼさ、短い 尾
- **きばが 巨大な つらら**。口の わきから 前へ 大きく 曲がり、先は 上へ とがる。氷の 段と 白い 光の すじ
- **背に 氷河の 岩**（灰色の 岩の 山に 氷の 面が 光る）
- もり上がった 額に 太い まゆ、その 下で 水色の つり目が にらむ（白い 光＋水色と 青の 2段の 虹彩＋ひとみ）
- **デフォルメ（2〜3頭身）**：頭を 大きく、胴は 小さく 丸く、足は 短い 柱。つららの きば（見せ所）は 大きい まま

## 足した もの／引いた もの
- 足した：つららの きば（こおり）、背の 氷河の 岩（いわ）
- 引いた：長い 鼻（短く 太く）、耳の 大きさ、毛の 細かい 流れ

## まぜた もの と 似ている 点
- マンモスの きば ⇔ つらら：どちらも「とがって 曲がる 細長い もの」。きばを そのまま 氷に して、つららの 段を つけた

## 見せ所
- 顔の 前で 大きく 曲がる 2本の つららの きば（体の 1/3 くらい）。攻撃では きばを 突き上げて 氷の かけらを 飛ばす

## はなれている もの（意図的）
- 攻撃の 氷の かけらは エフェクトなので はなれているのが 意図的
- きば・鼻・足・岩は 頭と 胴に 食いこませて つないである

## 色（GBA風・16色以内 → 14色）
輪郭 2（黒／こげ茶）・毛 3・岩 3（灰紫）・氷 3（白〜青）・白・口の 中・目の 光の 黄

## 動き
- 待機：胴が 上下し、氷河の 岩の 氷が きらりと 光る
- 歩き：短い 柱の 足を 交互に、重く 進む
- 攻撃：頭を 上げて ため → 前へ 突進して きばを 突き上げ、氷の かけらが 飛ぶ → ふりぬき
- 被弾：頭を 引いて 後ろへ
- ダウン：胴が くずれて ふせ、頭が 地面に 落ちる（目は ×）

## ゲーム上の 目安
- 体力と 攻撃が 高い・素早さは ひくい
- 技の 例：つららづき（こおり）、ひょうがおとし（いわ）、ふぶきの かべ（防御アップ）
