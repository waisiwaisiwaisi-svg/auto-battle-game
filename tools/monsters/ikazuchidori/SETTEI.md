# イカヅチドリ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。羽ばたくと 雷鳴が とどろく 嵐の 大鷲。黄色い とげとげの 鳥では なく、嵐雲の 色の 体に 稲妻を まとう 姿に する。

| 項目 | 内容 |
|---|---|
| タイプ | でんき ／ ひこう（風） |
| もとの 生き物 | 雷鳥（神話の サンダーバード）＋ 大鷲 |
| 分類 | らいうん モンスター（約52×58） |
| 性格 | いばりんぼうで 好戦的。嵐の 前に 現れ、高い 木や 塔に 雷を 落として なわばりを しめす |
| すみか | 雷雲の 中、雷が よく 落ちる 岩山の てっぺん |

## 見た目
- 体は 嵐雲の ような 青灰色。首まわりに 白い 雲の たてがみ、胸も 雲の 色
- 頭に 2本の 避雷針の ような ぎざぎざの 角、先が 黄色く 帯電する
- まゆの 重い 鷲の 顔。金色の 太い かぎくちばし、目は 水色に 光る
- 翼の 上の ふちが 稲妻の ぎざぎざ（3本の とがった 山）。翼を 横切って 黄色い 稲妻の 帯
- 尾は 稲妻形に 折れた 3本の 羽。金の かぎ爪

## 色（GBA風・16色以内 → 12色）
輪郭 2（黒／こい紺）・羽 3（青灰）・雲 2・電気 3（黄・水色・白）・くちばし／爪 2（金）

## 動き
- 待機・歩き（はばたき）：翼を 上 → 横 → 下 → 横 と はばたき、体が 上下
- まばたき：目が 閉じる
- 攻撃：翼を 上げて 角に 放電（ため）→ くちばしから 前へ 稲妻を 放つ → 前で 火花が はじける
- 被弾：首を 引いて 後ろへ
- ダウン：地面に 横たわり、翼は 地面に たれる。角の 電気は 消えて 灰色になり、けむりが 上がる（目は ×）

## ゲーム上の 目安
- 特攻が 高く、素早さも 高め。HPは ふつう
- 技の 例：らいめいの つばさ（でんき）、あらしの かぜ（ひこう）、ひらいしん（でんき技を 受けて 特攻アップ）
