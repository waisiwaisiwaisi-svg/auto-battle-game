# 手打ち GBA風 モンスターの 作り方（共通ルール）

お手本：`tools/monsters/magmajiro/`（SETTEI.md と mon.py を 必ず 読むこと）

## 設定の ルール
- **属性タイプ ＋ モンスター**。元に なる 生き物（実在・架空 どちらも可）を 「戦う ための 怪物」に する。かわいい 動物に しない
- 目は **するどく**（つり目・たての ひとみ・光る 目・まゆの ひさし など）。つぶらな 黒目は 使わない
- 牙・爪・角・とげ・よろい など 戦う 要素を 入れ、**属性が 見て わかる** 要素（溶岩・氷の 結晶・葉や いばら・火花・毒の ふくろ・霊火 など）を 必ず 入れる
- **既存作品（ポケモン・デジモン・ドラクエ 等）に 似せない**。デザインも 名前も オリジナル
- 設定は `SETTEI.md` に（お手本と 同じ 項目：タイプ・もとの 生き物・分類・性格・すみか・見た目・色・動き・ゲーム上の 目安）

## 絵の ルール（GBA ポケモン風）
- 右向き、**横〜3/4 横向き**（正面は 不可）
- 待機コマ（idle0）は **64×64 以内**。大きさの 目安：S 40〜46、M 48〜56、L 58〜64（いちばん 長い 辺）
- **16色以内**（パレットの 文字数で 数える）。輪郭は `k`＝黒（#101018 前後）と `l`＝体色の 濃い色（セルアウト・内側の 線）の 2色。各素材は 3段階（明・中・暗）
- 光は **左上** から。上と 左の ふちに 三日月の ハイライト、右下は 影。中間色の 広い 面は 作らない
- ディザ（市松）は 翼・膜・大きな グラデーションに だけ ひかえめに
- `l` が パレットに あると、エンジンが 自動で「内側の 黒線 → l」「光側の 外輪郭 → l」に する（`LIGHT` に 明るい色の 文字を 入れる）
- **1ドットずつ 手で 打つ** のが 基本。下書き（あたり）に `pix.poly / ellipse / line` を 使うのは 可だが、陰影・模様・目・牙などの 仕上げは 手で 打つ
- 拡大画像（anim.gif / frames.png を Read）で 必ず 見て、**最低 3回は 直す**。形が ぼやける・顔が 読めない・色が 平ら・浮いた パーツ が ないか

## 動き（14コマ：idle0〜3, blink, walk0〜3, atk0〜2, hit, ko）
- パーツ（グループ）ごとの **1〜3ドットの ずらし** と **差しかえ絵**（目・口・翼の 角度・攻撃の エフェクト など）で 作る。回転は 90度 以外 禁止
- idle：呼吸（胴や 頭が 1ドット 上下）＋ 属性の ゆらぎ（炎・火花・霊火の 差しかえ）
- blink：目を 閉じる（細い 線）
- walk：足（legA / legB）を 交互に、胴が 弾む。足の ない 型（浮遊・ヘビ・魚）は 体の うねり や 上下
- atk0：ため（後ろに 引く・身を ふせる・目が 光る）、atk1：攻撃の 決め（前へ とびこむ・口を 開く・爪を ふる・ブレス／エフェクト）、atk2：ふりぬき
- hit：後ろへ のけぞり、目は 苦しい 形
- ko：たおれる（専用の 差しかえ絵 か `'_flip': True`）、目は ×

## mon.py の 形（お手本と 同じ）
```python
META = dict(id='xxx', name='ナマエ', types=['fire', 'dark'], base='オオカミ', size='M')
PAL = {'k': '#101018', 'l': '#...', ...}      # 16色以内
LIGHT = set('...')                             # 明るい 色の 文字（セルアウト用）
PARENT = {'head': 'body', 'body': 'root', 'legA': 'root', 'legB': 'root', ...}   # グループの 親子
def layers(): return [dict(n=名前, g=グループ, x=, y=, rows=[...], alt={'atk1|atk2': [...]}, only='atk1', not_='ko'), ...]  # 奥 → 手前の 順
FRAMES = {'idle0': {}, 'idle1': {'body': (0, 1)}, ..., 'ko': {'_flip': True}}       # 14コマ
```
- 座標は 64×64 の 中の 位置（左上が 0,0）。足もとは y=60 前後に そろえる
- タイプ名：normal fire water grass elec ice fighting poison ground wind psychic bug rock ghost dragon dark steel fairy
