# ムシャボロ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。中身の ない よろいに 霊火が 宿った 武者の 怪物。かわいくせず、かぶとの 奥から にらむ 目で こわく。

| 項目 | 内容 |
|---|---|
| タイプ | ゴースト ／ はがね |
| もとの 生き物 | 空の よろい武者（古戦場の 大鎧） |
| 分類 | ぼろよろい モンスター（約49×47・デフォルメ 2〜3頭身） |
| 性格 | 無口で しつこい。一度 刀を 向けた 相手は 夜明けまで 追いかける。弱い 者には 刀を 抜かない |
| すみか | 古い 合戦場や くずれた 城の 武具蔵。霧の 夜に 歩きまわる |

## 見た目
- 鉄の かぶとに 金の 鍬形（くわがた）。かぶとの 中は からっぽの 闇で、つり上がった 霊火の 目だけが 光る（白い 光＋水色と 青緑の 2色＋たての ひとみ、上は ひさしで 切れる）
- 口もとは 牙の ある 面頬（めんぽお）。しころは 赤い おどし糸の 3段
- 胴の 胸に やぶれ穴が あり、中から 霊火が 見える（＝中身が ない）。袖・草摺は ぼろぼろの 赤糸おどし
- うでと 足の すき間は 体の かわりに 霊火で つながっている。**籠手・すね当てが 胴から はなれているのは 意図的**（中身の ない よろい）。すき間には かならず 霊火を 置き、ひとつの 体に 見えるように している
- デフォルメ（2〜3頭身）：かぶとは 元の 大きさの まま、胴・袖・草摺を 1段ずつ 短く、すね当ても 短く 太く（かぶとの 高さ ≒ 全体の 43%）。刀は かぶとの 後ろを 通して 顔を かくさない
- かぶとの 後ろから 霊火の 吹き流しが 立ちのぼる（ゴースト の しるし）
- 刀を 右上へ かまえ、足を 大きく ひらいた 低い かまえ

## 色（GBA風・16色以内 → 13色）
輪郭 2（黒／こい紫）・鋼 3・おどし糸 2（赤）・金 2（鍬形・つば）・霊火 3（白・水色・青緑）・白（刃・面頬の 牙）

## 動き
- 待機：胴が 1ドット 上下、吹き流しの 霊火が ゆらぐ
- まばたき：目の 霊火が 細く なる
- 歩き：重い すね当てを 交互に、胴が はずむ
- 攻撃：刀を 立てて 霊火を まとわせる（ため・目が 全開）→ 前へ ふみこんで 横一文字、霊火の 三日月の 斬撃 → 刀を 前下へ ふりぬく
- 被弾：上体が のけぞり、刀が 下がる
- ダウン：中身が ぬけて よろいが くずれ落ち、かぶとが 山の 上に のる（目は ×、霊火が 小さく 消えかける）

## ゲーム上の 目安
- 防御が 高く、攻撃も 高め。素早さは 低い
- 技の 例：おにびぎり（ゴースト）、はがねの よろい（防御アップ）、うらみの 一太刀（ゴースト・反撃）
