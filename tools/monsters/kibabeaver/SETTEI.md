# キババーバー

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | ノーマル ／ みず |
| もとの 生き物 | ビーバー |
| 分類 | のみば モンスター（第1形態・約54×31） |
| 性格 | がんこで 力じまん。川を せき止めた なわばりに 入る ものは、橋でも 船でも かじって しずめる |
| すみか | 森の 川の 上流。自分で かじり たおした 大木で 巨大な ダムを つくる |

## 見た目
- まるく もり上がった 背中の 重い 体。赤茶の 毛は いつも ぬれて いて、背中に 水てきが 光る
- 頭は 大きく、太い まゆの 下で 水色の 目が 光る つり目。ほおに 古い きずあと
- 口から 下へ つき出た オレンジの のみの 歯。木も 鉄も けずる
- しっぽは 丸太の ような 太い 尾。木の 皮の すじと 切り口の 年輪が あり、先から 水が したたる
- 後ろ足には 青い 水かき。足もとに いつも 水たまり

## 色（GBA風・16色以内 → 14色）
輪郭 2（黒／こげ茶）・毛 3・歯 2（明るい オレンジ／オレンジ）・丸太 3・水 3・白

## 動き
- 待機：体が 1ドット 上下、しっぽから 水が したたり、足もとの 水たまりが ゆれる
- 歩き：短い 足で 重く 進み、丸太の しっぽが 上下に ゆれる
- 攻撃：丸太の しっぽを まっすぐ 上へ ふり上げて ため（歯と 目が 光る）→ 地面に たたきつけて 水しぶき、前へ 大波を 走らせる → 波が 前へ ぬける
- 被弾：頭を はね上げて のけぞる
- ダウン：ひっくり 返る

## ゲーム上の 目安
- 体力と 攻撃が 高い。素早さは ひくめ
- 技の 例：のみばかみ（ノーマル・防御を さげる）、まるたたたき（ノーマル）、おおなみ（みず）
