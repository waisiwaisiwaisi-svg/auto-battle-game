# ヒノコギリ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | ほのお ／ はがね |
| もとの 生き物 | ノコギリザメ |
| 分類 | ねっこうのこ モンスター（約64×37） |
| 性格 | しつこく 獲物を 追い回す 狩人。のこぎりの 吻が 赤く 焼けるほど 機嫌が 悪い |
| すみか | 海底火山の 熱水が わく 深み。熱で 吻の 刃を 焼きなおしている |

## 見た目
- 体は 鋼の 板を びょうで 止めた よろい。頭の 上は 黒鉄の かぶと板
- えらは 3本の 赤熱した すじ。背びれの ふちも 赤く 焼けている
- 長い 吻は 黒鉄の 刃。上下に 赤熱した 三角の 歯が 並ぶ
- 口の 中は 赤く、上あごの 牙が のぞく
- **デフォルメ（2〜3頭身）**：頭を 大きく 丸く、胴は 小さく 短く、尾びれと 胸びれは 短く。のこぎり（見せ所）は 大きい まま
- 目は 魚の 目（K型）：まぶたの ない 丸い 目。黒鉄の 骨の ふち（いぼ つき）の 中に 赤熱した 細い 輪（黄→だいだい→赤）、まん中は 平たい 大きな 黒い 瞳。まばたきは 白い 膜が かかり、ためでは 輪が 白く 燃え 瞳が せばまる。ダウンは ×

## 足した もの／引いた もの
- 足した もの：赤熱した 歯・えら・背びれの ふち（ほのお）、鋼の 板と びょう（はがね）
- 引いた もの：ひげ、腹びれ・しりびれ、こまかい うろこ（板 2〜3枚に まとめた）

## まぜた もの と 似ている 点
- ノコギリザメの 吻の 歯 ⇔ 赤熱した のこぎりの 刃：どちらも「細長い 板の ふちに とがった 歯が 等間隔に 並ぶ」。吻の 歯を そのまま 焼けた のこぎりの 歯に 置きかえた

## 見せ所
- のこぎりの 吻（黒鉄の 刃＋赤熱した 大きな 歯の 列）。攻撃で 歯が 全部 赤く 焼け、突進して 火花を 散らす

## はなれている もの（意図的）
- 攻撃の 火花（atk1）と 切り裂きの 軌跡（atk2）は エフェクトなので はなれている（意図的）
- それ以外の 手足・首・尾・ひれ・翼・角は、どの コマでも 付け根を 体に 2〜3ドット 重ねて つないでいる

## 色（GBA風・16色以内）
輪郭 2（黒／濃い 紺）・鋼 3・黒鉄 2・赤熱 3（黄・だいだい・赤）・腹 2・白

## 動き
- 待機：体が 1ドット 上下し、胸びれが ゆれる
- 移動：尾と 胴が 交互に うねって 泳ぐ
- 攻撃：身を 引いて ため（歯が 赤熱・目が 全開）→ 口を 開けて 突進、刃から 火花 → のこぎりを 振りぬく
- 被弾：後ろへ はじかれ、目を ゆがめる
- ダウン：腹を 上に して ひっくり返る（目は ×）

## ゲーム上の 目安
- 攻撃と 素早さが 高い・特防は 低い
- 技の 例：ねっこうのこぎり（ほのお）、はがねぎり（はがね）、ねつだんとっしん
