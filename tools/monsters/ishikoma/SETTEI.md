# イシコマ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。神社の 狛犬（阿形）が 石の まま 動きだした 「念力で ほえる 番犬」。目は するどく。

| 項目 | 内容 |
|---|---|
| タイプ | いわ ／ エスパー |
| もとの 生き物 | 狛犬（阿形） |
| 分類 | まもりいし モンスター（約51×52） |
| 性格 | 忠実で がんこ。境内に 入る 悪い ものを 見ぬき、額の 宝珠を 光らせて 念力の ほえ声で 追いはらう |
| すみか | 山の 古い 神社の 参道。昼は 台座の 上で 石の ふりを している |

## 見た目
- **デフォルメ（2〜3頭身）**：頭は 大きく、胴は 小さく 丸く、足は 短く 太い 石の 足
- たてがみは **石灯籠の 笠** の ような 3段。のきの 先が 反りあがり、笠の すそに 石の 巻き毛（渦）が 並ぶ。いちばん 上に 宝珠の つまみ
- 口は いつも 大きく 開いた 「阿」の 形。上下に 牙、赤い 舌
- 額に 桃色の **宝珠**（念力の みなもと）。太い 石の まゆ、鼻の しわ
- しっぽは 宝珠形に 巻く 石の 炎
- **目**：三白眼（C）。大きく 見開いた 白目に、小さな 金の 虹彩（明・暗）と 点の ひとみが 上の 前に 寄る。上まぶたは 細く 前へ 下がり、下まぶたの 線は 太く 濃い（黒＋石の 影）。上に 太い 石の まゆ。にらみつける 狛犬の 目（まばたき＝線、ため・攻撃＝虹彩が 念力の 桃色に 光る、被弾＝ぎゅっと つぶる、ダウン＝×）
- **つなぎ方**：頭は たてがみ（笠）の 前に 重なり、たてがみは 胴に かぶさる。しっぽ・足は 胴に 食いこむ。攻撃の 念力の 輪だけは はなれているのが 意図的（エフェクト）

## 足した もの／引いた もの
- 足した：石灯籠の 笠の 段（たてがみ）、額の 宝珠
- 引いた：細かい 毛の 巻き（すその 渦だけに）、台座、足の 模様

## まぜた もの と 似ている 点
- 狛犬の たてがみの 巻き毛 ⇔ 石灯籠の 笠：どちらも **段に なって 外へ 反りかえる 形**。巻き毛の 段を そのまま 笠の 段と のきの 反りに した

## 見せ所
- **阿の 大口**（顔の 前 半分を しめ、牙が ずらりと 並ぶ）

## 色（GBA風・16色以内 → 12色）
輪郭 2（黒／こい 灰）・石 3・宝珠 2（桃・赤むらさき）・口の 中 2・目 2（金）・白

## 動き
- 待機：胸が 上下し、宝珠が ときどき 光る
- 歩き：短い 4本足で どっしり 進む
- 攻撃：身を ふせて ため（目と 宝珠が 光る）→ 口を さらに 開いて 念力の ほえ声（輪）を 放つ → 輪が 広がる
- 被弾：頭を そらして のけぞる
- ダウン：ひっくり 返る（目は ×）

## ゲーム上の 目安
- 防御と 特攻が 高め・素早さは 低い
- 技の 例：あぎょうのほうこう（エスパー）、いしだたみくずし（いわ）、まもりのかまえ（防御アップ）
