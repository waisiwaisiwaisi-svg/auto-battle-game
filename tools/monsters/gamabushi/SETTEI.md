# ガマブシ

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい カエルではなく、ガマガエルを 「刀を ふるう 武者」に した 怪物。

| 項目 | 内容 |
|---|---|
| タイプ | みず ／ かくとう |
| もとの 生き物 | ガマガエル |
| 分類 | すいとう むしゃ モンスター（約56×56） |
| 性格 | 無口で 義理がたい。一度 ねらった 相手は 決して のがさず、刀を くわえた まま じっと 間合いを はかる |
| すみか | 山おくの 滝つぼ。滝に うたれて 水の 刀を きたえる |

## 見た目
- 横はばの ある ずんぐりした 二足の ガマ。すもうの ように 足を ひらいて 低く かまえる
- 頭の てっぺんに 出っぱった 目玉。金色の 虹彩に 横長の ひとみ、黒い まぶたが 前へ つり下がって にらむ
- 口は 顔の はしまで さけた 一文字。赤い 舌で **水で できた 刀** の つかを まき取り、くわえて かまえる
- 朱ぬりの 小さな かぶと（前立ては 水の 三日月）、肩に 大袖、腰に 草ずりの よろい
- 皮は 青みどりで いぼだらけ。はらは クリーム色の じゃばら。太い うでの 先は 大きな こぶし

## 色（GBA風・16色以内 → 15色）
輪郭 2（黒／こん）・皮 3・はら 2・朱の よろい 3・水の 刀 3（白／水色／青）・金（目・つば）・舌の ピンク

## 動き
- 待機：呼吸で 胴が 上下。刀の 先から 水の しずくが たれる
- 歩き：がにまたで 重く ふみ出す
- 攻撃：刀を 舌で 上へ 立てて ため（目が 光る）→ 舌が のびて 刀を 前へ つき出す ＋ こぶしで 突き → 刀を ふりおろし 水の 三日月を のこす
- 被弾：のけぞって 目を ゆがめる
- ダウン：あおむけに たおれ、刀を 落とす（目は ×）

## ゲーム上の 目安
- 攻撃・HPが 高め、素早さは ふつう
- 技の 例：みずがたな（みず）、したづき（かくとう・先制）、たきうち（みず・こうげきアップ）
