# カガミカブト（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | エスパー ／ はがね |
| もとの 生き物 | カブトガニ |
| 分類 | どうきょう モンスター（第1形態・約55×40） |
| 性格 | 古風で 無口。鏡に うつした 相手の 心を 読み、念力で はね返す |
| すみか | 古い 社の 近くの 干潟。何百年も 姿が 変わらない |

## 見た目
- 背中の 甲羅は 丸い 銅鏡：銅の ふち（きざみ模様）と 光る 鏡の 面、ななめの 光の すじ
- 鏡の まん中の 鈕（つまみ）が **第三の 目**（むらさき）
- 前に 馬てい形の 銅の 頭の 板。むらさきの つり目、口に 牙と 小さな はさみ
- 後ろに 小さい 六角の 腹（ふちに とげ）と 鋼の 尾剣
- 鋼の 短い 脚（前は 前へ、後ろは 後ろへ ひらく）
- **デフォルメ（2〜3頭身）**：頭の 板は 全体の 約40%、見せ所の 鏡は 大きい まま。脚は 4本に へらし 短く

## 足した もの／引いた もの
- 足した：鏡の 面、銅鏡の きざみ、鈕の 第三の 目、牙
- 引いた：脚の 本数（10本 → 見える 4本）、腹の 細かい とげ、甲羅の 細かい みぞ

## まぜた もの と 似ている 点
- カブトガニの 丸い 甲羅 ⇔ 銅鏡：どちらも「丸く 平らな 板で、ふちが 一段 高い」
- 銅鏡の まん中の 鈕 ⇔ 第三の 目：どちらも「円の 中心の 小さな 丸い でっぱり」

## 見せ所
- 銅鏡の 甲羅。体の 半分の 大きさで、攻撃では 鏡が むらさきに 光り 念力の 光線を 出す

## 色（GBA風・16色以内 → 15色）
輪郭 2（黒／こげ茶）・銅 3・鏡 3（白〜青）・念力 2（むらさき）・鋼 3（脚・尾剣）・白・口の 中の 赤

## 目
- 顔の 目：白い 光 ＋ むらさきの 虹彩（明・暗）＋ ひとみ。まゆと 下まぶたで かこむ
- 第三の 目：白い 光 ＋ むらさき（明・暗）＋ たての ひとみ。銅の まぶたの 輪で かこむ
- まばたき＝閉じる、被弾＝ゆがんだ 線、ダウン＝×

## 動き
- 待機：甲羅が 1ドット 上下、鏡に 光の つぶが 走る、尾剣が ゆれる
- 歩き：短い 脚を 交互に
- 攻撃：鏡が むらさきに 光り（ため）→ 第三の 目から 前へ 念力の 光線、口を 開ける → 念力の 輪が 残る
- 被弾：後ろへ 下がり 頭を 下げる
- ダウン：あおむけに ひっくり 返る（カブトガニらしく 脚が 上。目は ×）

## はなれている もの（意図的）
- atk2 の 念力の 輪、待機の 光の つぶは エフェクト

## ゲーム上の 目安
- 防御と 特殊防御が 高い・素早さ 低い
- 技の 例：かがみがえし（エスパー・受けた 技を 返す）、どうきょうビーム（はがね）、こころよみ（命中アップ）
