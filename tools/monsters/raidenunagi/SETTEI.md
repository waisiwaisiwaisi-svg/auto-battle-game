# ライデンウナギ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | でんき ／ みず |
| もとの 生き物 | ウナギ（デンキウナギ） |
| 分類 | はつでんばん モンスター（第1形態・約56×38） |
| 性格 | 短気で 好戦的。近づく ものには まず 電撃を あびせ、しびれて 動けなく なった 獲物を 丸のみに する |
| すみか | 雷雨の 多い 沼や 河口。嵐の 夜に 水面へ 上がって 雷を 吸う |

## 見た目
- 黒みがかった 紺色の 長い 体を S字に うねらせ、地面の 少し 上を 泳ぐ
- わき腹に 発電板（黄色い 板）が 一列に 並び、怒ると 白く 光る（でんきタイプ）
- 背びれ・頭の つの・尾の 先は 稲妻の 形の 黄色い ひれ
- 頭は 平たく 口が 大きい。光る つり目と、細かい 針の ような 牙。ほおにも 発電板
- 腹は 水色が かった 灰色（みずタイプ）

## 色（GBA風・16色以内 → 13色）
輪郭 2（黒／濃紺）・体 3（紺）・腹 2（灰水色）・電気 3（白黄・黄・山吹）・白（光・牙）・水色（火花）・口の 中（暗い 赤）

## 動き
- 待機：体の 一部が 1ドット ずつ 上下に うねり、ときどき 頭の まわりに 火花
- 泳ぎ：4つの 体の 区切りが 交互に 上下し、波が 尾から 頭へ 伝わる
- 攻撃：身を 引いて 発電板が 白く 光る → 口を 開けて 全身から 放電、口から 電撃の 帯 → 電撃が 細く なって 終わる
- 被弾：頭を のけぞらせ、目が ゆがむ
- ダウン：腹を 上に して ひっくり返る

## ゲーム上の 目安
- 特殊攻撃と 素早さが 高い・防御は 低め
- 技の 例：ほうでんうねり（でんき）、しびれがみ（でんき・まひ）、だくりゅう（みず）
