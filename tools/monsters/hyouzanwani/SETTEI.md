# ヒョウザンワニ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | こおり ／ みず |
| もとの 生き物 | ワニ |
| 分類 | ひょうざん モンスター（約64×45） |
| 性格 | じっと 動かず 獲物を 待つ。近づいた ものは 大あごで 一気に くわえ、氷づけに して しまう |
| すみか | 流氷の 浮かぶ 寒い 河口。背の 氷山だけを 水面に 出して 隠れる |

## 見た目
- 背中の うろこの 突起は とがった 氷山の 頂（水色の 結晶）。いちばん 高い 頂が 背の まん中に 立つ
- うろこは 冷たい 青緑。腹と あごの 下は 白っぽい
- 頭は 大きく、目の 上の こぶに 金色の つり目。太い 上あごから 牙が はみ出す
- 足は 短く 太く、外へ ふんばる。白い かぎ爪
- **デフォルメ（2〜3頭身）**：頭と あごを 大きく、胴は 短く 丸く、足は 短く、尾も 短く。大あご（見せ所）と 氷山は 大きい まま
- 目は 白い 光＋金の 虹彩（明 黄・暗 だいだい）＋たての ひとみ。ぶあつい まゆの こぶで かこむ

## 足した もの／引いた もの
- 足した もの：背の 氷山（こおり）
- 引いた もの：長い 尾（短く）、背の こまかい うろこの 列（氷山 5つに まとめた）、指の 数

## まぜた もの と 似ている 点
- ワニの 背の うろこの 突起 ⇔ 氷山の 頂：どちらも「とがった 山が 列に なって 並ぶ」。うろこの こぶを そのまま 氷の 結晶の 山に 置きかえた

## 見せ所
- 大あご（太い 上あご と 牙）。攻撃で 上あごを 大きく ふりあげ、赤い 口の 中と 牙を 見せて かみつく

## はなれている もの（意図的）
- 攻撃の 冷気の つぶ（atk0・atk2）は エフェクトなので はなれている（意図的）
- それ以外の 手足・首・尾・ひれ・翼・角は、どの コマでも 付け根を 体に 2〜3ドット 重ねて つないでいる

## 色（GBA風・16色以内）
輪郭 2（黒／濃い 青緑）・うろこ 3・腹 2・氷 3（白・水色・青）・口の 中・目 2（金）・白

## 動き
- 待機：胴が 1ドット 上下し、尾が ゆれる
- 歩き：短い 足を 交互に、胴が はずむ
- 攻撃：身を ふせて ため（目が 全開・冷気）→ 大あごを ひらいて とびかかる → 閉じて 冷気が 飛ぶ
- 被弾：頭を 後ろへ そらし、目を ゆがめる
- ダウン：ひっくり返る（目は ×）

## ゲーム上の 目安
- 体力と 攻撃が 高い・素早さは 低い
- 技の 例：ひょうざんかみつき（こおり）、だくりゅう（みず）、こおりのよろい（防御アップ）
