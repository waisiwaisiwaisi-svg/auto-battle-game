# ワダツミ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | みず ／ ドラゴン |
| もとの 生き物 | 海竜（海へビ ＋ 竜） |
| 分類 | なみがしら モンスター（第1形態・約64×61） |
| 性格 | 誇り高く 執念深い。なわばりの 海を 荒らす ものは 何日でも 追いかけ、嵐ごと 呑みこむ |
| すみか | 渦潮の 底。とぐろを 巻いて 潮の 流れを 見張っている |

## 見た目
- 青緑の うろこの 長い 体。地面に とぐろを 巻き、首を S字に 高く 立てる
- 背中に くだける 波頭の 形の ひれ（みずタイプ）。前の ふちが 白い しぶきで、ゆれると しぶきが はねる
- 尾の 先は 大きな 波の 扇
- 頭は 長い 鼻先の 竜。ぶあつい まゆの 下で 金色の つり目が 光り、上あごに 牙が 並ぶ
- うしろへ 反った 金の 角が 二本（ドラゴンタイプ）。のどから 腹は 砂色の 板

## 色（GBA風・16色以内 → 14色）
輪郭 2（黒／濃い青緑）・うろこ 3（青緑）・腹の 板 2（砂色）・波 3（水色〜群青）・しぶきの 白・金 2（角・目）・口の 中（暗い 赤）

## 動き
- 待機：首が ゆっくり 上下し、波の ひれの しぶきが はねる
- 移動：首と とぐろが 交互に 1ドット うねる
- 攻撃：首を 引いて 目が 全開 → 口を 大きく 開けて 水の ブレスを 一直線に はく → ブレスが 細く なって 終わる
- 被弾：首を うしろへ そらし、目を ゆがめる
- ダウン：首が くずれ、頭が とぐろの 上に 落ちる（目は ×）

## ゲーム上の 目安
- 特殊攻撃と 体力が 高い・素早さは ふつう
- 技の 例：たいかいのいぶき（みず）、りゅうのうずしお（ドラゴン）、とぐろまもり（防御アップ）
