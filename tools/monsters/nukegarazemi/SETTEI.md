# ヌケガラゼミ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。セミの 抜け殻に 霊が やどり、「中身の ない よろい」として 動きだした 怪物。目は するどく。

| 項目 | 内容 |
|---|---|
| タイプ | むし ／ ゴースト |
| もとの 生き物 | セミ（の 抜け殻） |
| 分類 | ぬけがら モンスター（約49×53） |
| 性格 | 夏の 終わりに 目を さます 執念ぶかい 霊。羽化 できなかった うらみで、生きた 虫や 人に つかみかかる |
| すみか | 古い 寺の 大木の 幹。夜に なると 背の 裂け目から 青白い 霊火が もれる |

## 見た目
- **デフォルメ（2〜3頭身）**：頭は 大きく、腹は 小さく 丸い。浮かんで 移動する
- こはく色の 抜け殻。顔は セミらしい 横すじ、目の ふくらみ、針の 口。前足は ほり返す ための 大きな かぎ爪（ももの 下に とげ）
- **背の 裂け目**（頭の 後ろ〜腹）が ぎざぎざに 割れて 中は からっぽの 闇。そこから **青白い 霊火** が 翅の ように 立ちのぼる
- 中足・後足は 細く 小さく たれ下がる
- **目**：白い 光＋赤 2段＋たての ひとみ、まゆと 下まぶたの 線（殻の 中で 霊が 光る）
- **つなぎ方**：霊火の 翅は 裂け目の 奥から 出て、手前にも 霊火が こぼれて 裂け目に かさなる。前足は 頭に、細い 足は 腹に 食いこむ。攻撃の 斬撃の 線だけは はなれているのが 意図的（エフェクト）

## 足した もの／引いた もの
- 足した：背の 裂け目から 出る 霊火（翅の かわり）
- 引いた：本物の 翅、6本の 足の うち 中足（2本に まとめた）、腹の 細かい 毛

## まぜた もの と 似ている 点
- セミの 抜け殻 ⇔ 中身の ない よろい：どちらも **からっぽの 殻だけで 人の 形・虫の 形を 保つ**。殻の 裂け目を 霊火の 出口に した

## 見せ所
- **裂けた 背と そこから 燃えあがる 霊火**（頭より 高く 立つ）

## 色（GBA風・16色以内 → 12色）
輪郭 2（黒／こげ茶）・殻 3（こはく）・霊火 3（白青・水色・青紫）・闇 1・目 2（赤）・白

## 動き
- 待機：上下に ただよい、霊火が ゆらぐ
- 歩き（移動）：ふわふわと 上下しながら 前へ
- 攻撃：かぎ爪を ふりあげ 霊火が 高く 燃える（目が 光る）→ 前へ とびこんで かぎ爪で 切りさく → ふりぬき
- 被弾：頭を そらして のけぞる
- ダウン：ひっくり 返って 落ちる（目は ×）

## ゲーム上の 目安
- 素早さと 特攻が 高め・防御は 低い
- 技の 例：うつせみぎり（むし）、たまびのはね（ゴースト）、ぬけがらがえし（身代わり）
