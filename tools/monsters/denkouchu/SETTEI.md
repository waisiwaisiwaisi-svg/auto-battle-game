# デンコウチュウ

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。夏の 虫とりの カブトムシではなく、角で 雷を 呼びこみ 体に ためて 撃ちだす 「生きた 避雷針」の 怪物に した。目は するどく。

| 項目 | 内容 |
|---|---|
| タイプ | でんき ／ むし |
| もとの 生き物 | カブトムシ |
| 分類 | ひらいしん モンスター（第1形態・約61×48） |
| 性格 | 雷雨の 夜ほど 気が 立つ。ためた 電気が 満タンに なると 角を ふりあげて 相手を さがす |
| すみか | 落雷の 多い 高い 山の 森。雷に 打たれた 大木の 上で 雷雲を 待つ |

## 見た目
- 背中は つやの ある 紺の 前ばね。いなずま形の すじが 3本 あり、電気が たまるほど 1本ずつ 黄色く 光る（電池の めもりの ように）
- 頭の 角は 真ちゅう色の 太い 避雷針。前へ 出てから 上へ 反りかえり、先は ふたまた。根もとから 先まで 光る コイルが 4本 巻きつく
- 胸の よろいからも 短い 角が 前へ のび、頭の 角と はさみの 形を つくる
- 目は 重い まゆの 下で 電光色に 光る つり目。口もとに 白い 小あご
- 足は 6本。とげの ある 細い 足で 胴を 高く ささえる

## 色（GBA風・16色以内 → 12色）
輪郭 2（黒／こい藍）・甲羅 3・電気 3（黄・金・水色）・真ちゅう 3・白（つや・あご）

## 動き
- 待機：前ばねの すじが 1本→2本→3本と 充電され、角の 先で 火花が はじける
- 歩き：足を 2組 交互に 動かし、胴が はずむ
- 攻撃：身を ふせて 充電（すじ 全開・目が 黄色く 光り、体の まわりに 火花）→ 前へ 出て 角の 先から いなずまを 撃つ → いなずまの 先で 閃光
- 被弾：頭を さげて 後ろへ さがり、すじの 光が 消える
- ダウン：あおむけに ひっくり 返る（目は ×、すじは 消灯）

## ゲーム上の 目安
- 特攻・攻撃が 高い・防御は ふつう・素早さは ふつう
- 技の 例：ひらいしんボルト（でんき）、つのチャージ（むし）、じゅうでん（次の でんき技を 強化）
