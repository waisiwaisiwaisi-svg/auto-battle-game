# コオリミミズク（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。氷の 刃の 羽を もつ 夜の 狩人。まるい 雪だるまの フクロウでは なく、紺の 羽に つららの 刃を たらし、冷たく にらむ 怪物に する。

| 項目 | 内容 |
|---|---|
| タイプ | こおり ／ ひこう（風） |
| もとの 生き物 | ミミズク（羽角の ある フクロウ） |
| 分類 | つららばね モンスター（約52×35） |
| 性格 | 音を 立てずに 近づき、相手が 気づく 前に 氷の 羽を 撃ちこむ。ひとりで 狩る |
| すみか | 凍った 針葉樹林、吹雪の 山の 崖 |

## 見た目
- 背と 翼は 夜空の 紺。胸は 白く、水色の 横じま
- 羽角は 氷の 結晶で、後ろへ 反った 角の よう
- 顔の 上半分は 紺の まゆの 帯で おおわれ、その 下から つり上がった 水色の 目が 光る。小さな かぎくちばし
- 翼の 下ふちから、風切り羽の かわりに つららの 刃が 何本も たれる（こおりの しるし）
- 尾も 氷の 刃。足は 紺の 羽毛で、黒い かぎ爪を 前に 出す

## 色（GBA風・16色以内 → 11色）
輪郭 2（黒／こい紺）・白・氷 3（水色〜青）・紺の 羽 2・目の 光・くちばし 2

## 動き
- 待機・歩き（はばたき）：翼を 上 → 横 → 下 → 横 と はばたき、体が 上下
- まばたき：まぶたが 閉じる
- 攻撃：翼を 上げて 霜の 光（ため・目が 白く 光る）→ 翼を 打ちおろして つららの 羽を 3本 撃ちだす → 羽が さらに 前へ 飛ぶ
- 被弾：首を 引いて 後ろへ
- ダウン：地面に 落ちて 首を たれる（目は ×）

## ゲーム上の 目安
- 素早さと 攻撃が 高い。HPと 防御は 低め
- 技の 例：つららばね（こおり）、しのびかぜ（ひこう・先制）、こごえる まなざし（相手の 素早さダウン）
