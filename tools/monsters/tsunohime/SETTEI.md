# ツノヒメ

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | フェアリー ／ エスパー |
| もとの 生き物 | ユニコーン |
| 分類 | けっしょうやり モンスター（最終形態・約61×60） |
| 性格 | ほこり高く、決して 背に 人を 乗せない。みとめた 相手とだけ 一騎うちを する |
| すみか | 夜の 高原に ある 水晶の 谷。月の 光を 角に ためる |

## 見た目
- 夜空色（あい色）の 大きな 戦馬。胸に 金の むないた（水色の 宝石と 前へ つき出た 結晶の とげ）
- たてがみの かわりに ピンクの 結晶の とげが 首すじに 4本 並ぶ。しっぽも 結晶の たば
- 額から のびる 角は ねじれた 結晶の やり（らせんの きざみ）。鼻すじは 金の 面よろい
- 目は 水色に 光る つり目（黒い まゆの 線の 下）。口には 小さな 牙
- ひづめは 結晶、足首に 金の わ
- まわりに 念力で うかぶ 結晶の かけら（エスパー）

## 色（GBA風・16色以内 → 13色）
輪郭 2（黒／こい あい色）・体 3・結晶 3（白ピンク／ピンク／赤紫）・金 3・目の 水色・白

## 動き
- 待機：頭が 1ドット 上下、まわりの 結晶の かけらが ふわふわ 上下
- 歩き：4本の 足を 交互に
- 攻撃：前足を 上げて ため、角が 白く 光り、かけらが 角へ 集まる → とっしんして 角で つく。角の 先で 念力の 光が はじける → 光の わが 広がる
- 被弾：首を はね上げて のけぞる
- ダウン：ひっくり 返る

## ゲーム上の 目安
- 特攻と 素早さが 高い。防御は ふつう
- 技の 例：けっしょうランス（フェアリー）、ねんりきとっしん（エスパー）、かけらのたて（防御アップ）
