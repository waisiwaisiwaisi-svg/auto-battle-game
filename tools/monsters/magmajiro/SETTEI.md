# マグマジロ（仮）

| 項目 | 内容 |
|---|---|
| タイプ | ほのお ／ じめん |
| モチーフ | アルマジロ ＋ 冷えた溶岩（火山岩） |
| 分類 | ようがん よろいの モンスター（第1形態・小さめ 約48×36） |
| 性格 | おくびょうで 食いしんぼう。おどろくと まるまって ころがり だす |
| すみか | 火山の ふもとの あたたかい 砂地。夜は 甲羅の すき間が ぼんやり 光る |

## 見た目
- 背中の 甲羅は 黒っぽい 火山岩の 板が 3枚。板と 板の すき間から 赤い 溶岩が のぞき、ゆらゆら 光る
- 甲羅の ふちは 一段 濃い「スカート」。板の 表面には 小さな つぶつぶ（冷えた あわ）
- 顔は 小さく とがった 鼻、まるい 大きな 耳（内側は ピンク）、くりっと した 黒目
- 体と 足は 砂色の 毛。足は みじかく、つめは 白
- しっぽは 太く みじかく、先に 溶岩の しずくが ひとつ

## 色（GBA風・16色以内）
- 輪郭 2：黒／こげ茶（光側・内側の 線）
- 甲羅（火山岩）3：明・中・暗の 紫がかった 灰
- 溶岩 2：黄・オレンジ
- 毛 3：明・中・暗の 砂色
- 目・つめ 1：白、 耳の 内側・鼻 1：ピンク

## 動き
- 待機：呼吸で 甲羅が 上下、すき間の 溶岩が 明滅、耳が ぴくっ
- 歩き：みじかい 足を ちょこちょこ（手前と 奥が 交互）
- 攻撃：身を ふせて ため → まるまって ボールに → 転がって 体当たり（回転は 90度ずつ＝ドットが くずれない）
- 被弾：甲羅に 首を すくめる
- ダウン：ひっくり返って おなかを 見せる（目は ×）

## ゲーム上の 目安
- 得意：防御が 高い・素早さは 低い
- 技の 例：ころがりアタック（じめん）、ひのこ（ほのお）、まるくなる（防御アップ）
