# イワサイ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | いわ ／ じめん |
| もとの 生き物 | サイ |
| 分類 | とっしんがん モンスター（第1形態・約61×47） |
| 性格 | 短気で まっすぐ。動く ものを 見ると 地面を けって 突っこみ、岩でも 木でも くだく |
| すみか | 荒れた 岩の 高原。崖に 角を こすりつけて とぐ |

## 見た目
- 体は 黒っぽい 花こう岩の 皮。肩の 筋肉が 山の ように もり上がった くさび形
- 肩から 背中を 砂岩の よろいが おおい、ひびが 入っている。背骨に そって 岩の とげが 並ぶ
- 鼻先に 巨大な 砂岩の 角、その 後ろに 小さな 角。角には ひび
- 小さく 赤く 光る 目を 砂岩の まゆ板が おおう
- 太い 柱の ような 足、砂色の つめ

## 色（GBA風・16色以内 → 10色）
輪郭 2（黒／すみ色）・花こう岩 3・砂岩 3・目の 赤・白

## 動き
- 待機：鼻息で 体が 上下
- 歩き：どすどすと 重い 足どり
- 攻撃：頭を 下げ、後ろ足で 地面を けって 土けむり（ため）→ 全速力の 突進（土けむりと 風の 線）→ 角で かち上げ、岩の かけらが 飛ぶ
- 被弾：頭を 上げて 後ろへ
- ダウン：ひっくり 返る（目は ×）

## ゲーム上の 目安
- 攻撃と 防御が 高い・特攻は 低い
- 技の 例：がんせきとっしん（いわ）、じならし（じめん）、つのかちあげ（いわ・ひるませ）
