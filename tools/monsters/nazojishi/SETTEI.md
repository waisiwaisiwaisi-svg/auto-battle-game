# ナゾジシ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | エスパー ／ いわ |
| もとの 生き物 | スフィンクス（翼の ある 獅子の 石像） |
| 分類 | なぞかけいしぞう モンスター（第1形態・約51×59） |
| 性格 | 冷たく 誇り高い。遺跡に 入った 者に 問いを かけ、答えられない 者を 念力で 石に 変える |
| すみか | 砂に うもれた 古代の 神殿。何千年も 門の 前に すわって 見はっている |

## 見た目
- **デフォルメ（2〜3頭身）**：頭と 青石の たてがみは 大きい まま（全体の 約46%）。体は 小さく まとめた 「すわった 獅子」：立てた 胸、その 下に 太い 前足 2本（指と 白い 爪）、うしろに 小さく たたんだ もも と 前へ 出した うしろ足先。翼は 見せ所なので 大きく 上へ ひらく
- **はなれた パーツ**：念力の 光線と 念の 輪は エフェクトなので はなれているのが 意図的（足・しっぽ・翼・円盤は 体に 食いこませて つなぐ）
- 体は 砂岩で できた 獅子。胸を 立てて すわる 「守り獣」の かまえ。ももの ふちは 線で 分け、うしろから しっぽが 上へ 巻く（先は 念の 光の ふさ）
- 頭の 後ろに 青石の 円盤の たてがみ。ふちは ぎざぎざの とげ、念の 文字が ピンクに 光る
- 顔は 角ばった 石の 仮面。重い まゆの 下で ピンクに 光る つり目（白い 光＋ 2色の 虹彩＋ たての ひとみ、下に まぶたの 線）。額には **見せ所の 第三の 目**：青石の 台座に はまった 大きな たて長の 目（白い 光・2色の 虹彩・たての ひとみ）が 頭の 上へ 少し はみ出す
- 背中から 石の 翼が 左上へ ひらく（風切り羽の 先が ぎざぎざ、付け根に 雨おおいの 列）。奥の 翼は 暗い 色で 少し ずらす
- ももと 胸に うず巻きの 紋様の みぞ、念力が 高まると 光る。体の あちこちに 石の われ目

## 色（GBA風・16色以内 → 12色）
輪郭 2（黒／むらさき黒）・砂岩 3・青石 3・念力の 光 3・白

## 動き
- 待機：紋様と 第三の 目が ゆっくり 明滅、頭が 1ドット 上下
- 歩き：石像らしく 重く 一歩ずつ
- 攻撃：翼を 立て 第三の 目が 白く 開く（ため）→ 口を 開いて 第三の 目から 念力の 光線 → 光線の 先に 念の 輪
- 被弾：頭を さげて 後ろへ ずれる
- ダウン：ひっくり 返る（目は ×、第三の 目は 閉じる）

## ゲーム上の 目安
- 防御・特攻が 高い・素早さは 低い
- 技の 例：サードアイビーム（エスパー）、なぞかけの 呪い（エスパー・いし化）、がんせきプレス（いわ）
