# テッケンザル

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。森の おさるではなく、大猿を 「鉄の こてで なぐりつける 剛力の 怪物」に した。

| 項目 | 内容 |
|---|---|
| タイプ | かくとう ／ はがね |
| もとの 生き物 | 大猿（ゴリラ） |
| 分類 | てっけん モンスター（約59×53） |
| 性格 | むれの ボス。だまって 相手を にらみ、ゆるさないと 決めたら 鉄の こぶしを 地面に たたきつけて 合図する |
| すみか | 廃坑の おく。鉄くずを 集めて こてを 打ちなおす |

## 見た目
- 肩が いちばん 高く、背中が 後ろへ 下がる ゴリラの 体。長い 腕を 地面に つく ナックル歩き
- 両手に **はがねの 巨大な こて**（びょう打ち、指の 関節に 鉄板）
- 背中に 太い **鎖** を たすきがけに 巻く。こぶしと 鎖は つながっていて、鉄拳を 鎖ごと 打ち出せる
- 灰色の 顔に 鉄の はちがね（ひたいあて）。その 下で 赤い 目が 光り、下の きばが 上へ つき出る
- 毛は 赤黒い こげ茶。背中の 毛の すじは 光の 当たる 左上ほど 明るい

## 色（GBA風・16色以内 → 13色）
輪郭 2（黒／赤黒）・毛 3・顔の はだ 2・はがね 3・赤と だいだい（目・口・火花）・白（きば）

## 動き
- 待機：胴と 頭が 上下、こてを つきなおす
- 歩き：こぶしと 足を 交互に ついて のしのし 進む
- 攻撃：鉄の こぶしを 頭の 上へ ふりかぶる（目が 光る）→ こぶしを **鎖ごと 前へ 発射**、当たって 火花 → 鎖を 引いて こぶしが もどる
- 被弾：頭を 引いて ほえる
- ダウン：ひっくり 返る（目は ×）

## ゲーム上の 目安
- 攻撃・防御が 高い、素早さは とても ひくい
- 技の 例：くさりてっけん（はがね・遠くの 相手にも とどく）、じならし（かくとう）、てつのかまえ（はがね・防御アップ）
