# ヒムカデ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | むし ／ ほのお |
| もとの 生き物 | ムカデ |
| 分類 | おきびあし モンスター（第1形態・約56×39） |
| 性格 | 気が 短く、熱い ものに 向かって まっすぐ 突っこむ。歩いた あとの 草は こげて 黒い すじに なる |
| すみか | 火山の ふもとの 岩の すき間や、焼けた 森の 灰の 下 |

## 見た目
- 黒赤の 甲の 節が つらなる 長い 体。節の すき間から 溶けた 火が 光る
- 足の 一本一本の 先が 熾火（おきび）のように 光る（ほのおタイプ）。体の 前の 方だけ 持ち上げる
- 頭は 平たい 甲の かぶと。光る つり目
- 頭の 下から 前へ 曲がった 大きな 毒あご（顎肢）。先が 熾火色
- 前へ のびる 二本の 触角の 先と、尾の 二本の 尾脚の 先に 炎。背中から 火の 粉が 舞う

## 色（GBA風・16色以内 → 11色）
輪郭 2（黒／黒赤）・甲 3（赤〜黒赤）・腹 2（こはく色）・炎 3（白黄・だいだい・朱）・白（予備）

## 動き
- 待機：体の 前が 1ドット 上下し、触角の 炎と 火の 粉が ゆれる
- 歩き：足の 列（手前・奥）が 交互に 前へ 出て、体が はずむ
- 攻撃：前を 持ち上げて 毒あごを 広げ、目が 全開 → 前へ とびこみ、あごの 先から 炎を ふき出す → 炎が 小さく なって ふりぬく
- 被弾：うしろへ 下がり、頭を そらす
- ダウン：あおむけに ひっくり返り、足が 上を 向く

## ゲーム上の 目安
- 攻撃と 素早さが 高い・防御は 低め
- 技の 例：ほのおのあご（ほのお）、ひゃくそくらっしゅ（むし）、ひのこまき（やけど）
