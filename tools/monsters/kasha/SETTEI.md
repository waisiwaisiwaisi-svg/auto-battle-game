# カシャ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | ほのお ／ あく |
| もとの 生き物 | 猫 |
| 分類 | ひぐるま モンスター（第1形態・約55×44） |
| 性格 | 執念深く 気まぐれ。夜道で 燃える 車輪の 音を ひびかせ、獲物を どこまでも 追う |
| すみか | 古い 寺や 墓地の 夜道。火の 粉の あとを 残して 走る |

## 見た目
- 闇の 黒紫の 毛並みの 猫。背の 毛が 逆立ち、体の ところどころに 熾火（おきび）の しまが 光る
- **丸めた 尾が そのまま 燃える 車輪**。鉄の たがと 4本の 輻（や）、輪の 中心は 燃える 芯、外がわから 炎が なびく
- とがった 耳の 中は 熾火の 赤。ほおに くまどり、ほおの 毛は ぎざぎざの 房
- 光る目（E）：瞳の ない 炎の 目。白い 芯＋黄と だいだいの 発光、黒い 輪郭の かわりに 赤い 1ドットの にじみが ふちどり、後ろ上へ 火の 粉の 尾を ひく つり目形（まばたきは 光が 細い すじに、被弾は 光が 割れる、ダウンは 消えた 熾火の ×）。口から 白い 牙が のぞく
- **デフォルメ（2〜3頭身）**：頭を 大きめ（全体の 約4割）、胴は 小さく 丸く、足は 短く 太い。車輪（見せ所）は 大きい まま

## 足した もの／引いた もの
- 足した：燃える 車輪の 尾（ほのお）、熾火の しまと くまどり（あく・ほのお）
- 引いた：ひげ・細かい 毛の 模様・長い 足（短く 太く まとめた）

## まぜた もの と 似ている 点
- 丸めた 猫の 尾 ⇔ 燃える 車輪：どちらも「くるりと 閉じた 輪」。尾の 先を 根もとへ つなげて 輪に し、そこへ 輻と 炎を 入れた

## 見せ所
- 尾の 燃える 車輪（頭と 同じ くらいの 大きさ）。待機中も 輻が 回り、炎が なびく

## はなれている もの（意図的）
- 攻撃の 炎の 爪あと（3本の 弧）は エフェクトなので はなれているのが 意図的
- 車輪は 尾の 根もとで 胴の 中まで 食いこませて つないである

## 色（GBA風・16色以内 → 13色）
輪郭 2（黒／濃い紫）・毛 3（黒紫）・炎 4（黄・だいだい・赤・暗い 赤）・鉄 2・白（牙・爪）・口の 中の ピンク

## 動き
- 待機：呼吸で 胴が 上下し、車輪の 輻が 回って 炎が ゆれる
- 歩き：短い 足を 交互に 出して 弾む
- 攻撃：身を ふせて ため → 前へ とびかかり 口を 開いて 炎の 爪で 切りさく → ふりぬき
- 被弾：首を すくめて 後ろへ
- ダウン：胴が くずれて 地面に ふせ、頭を 横たえる（目は ×、炎は 消える）

## ゲーム上の 目安
- 攻撃と 素早さが 高い・防御は ひくい
- 技の 例：ひぐるまだっしゅ（ほのお）、やみの つめ（あく）、おにび（相手を やけど）
