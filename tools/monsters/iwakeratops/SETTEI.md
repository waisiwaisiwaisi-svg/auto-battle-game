# イワケラトプス（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | いわ ／ ドラゴン |
| もとの 生き物 | トリケラトプス |
| 分類 | かせきりゅう モンスター（第1形態・約63×55） |
| 性格 | がんこで 退かない。群れの 先頭に 立ち、えりを 立てて 敵を にらみつける |
| すみか | 地層が むき出しの 断がい。化石を かじって 骨の えりを 太くする |

## 見た目
- 体は 赤茶色の 岩の 皮。六角形の 岩板が われ目で 区切られている
- 頭の 後ろに 大きな 化石の えり。ふちは とげの 輪、中には 扇の 骨すじと アンモナイトの 化石紋
- 額に 長い 骨の 角が 2本、鼻先に 短い 角。口は 骨の くちばし
- 背骨に そって 竜の 青緑の うろこ板が 並ぶ
- こはく色の するどい 目（まゆの 下）

## 色（GBA風・16色以内 → 13色）
輪郭 2（黒／こげ赤）・岩の 皮 3・化石の 骨 3・竜の うろこ 2・こはく 2・白

## 動き
- 待機：えりの 化石紋が こはく色に 明滅
- 歩き：太い 足で ずしずしと
- 攻撃：前足を 高く 上げて 立ち上がる（ため・化石紋が 光る）→ 地面を 踏みつけ、衝撃で 岩が はね上がる → 土けむりの 波
- 被弾：頭を 上げて 後ろへ
- ダウン：ひっくり 返る（目は ×）

## ゲーム上の 目安
- 防御・攻撃が 高い・素早さは 低い
- 技の 例：かせきスタンプ（いわ）、みつづのづき（ドラゴン）、こはくの にらみ（相手の 攻撃ダウン）
