# ヤミダイオウ（仮）

**設定の ルール：属性タイプ ＋ モンスター（戦う ための いきもの）**。かわいい 動物ではなく、元になった 生き物を 「戦う 姿」に 変えた 怪物として 作る。目は つぶらにせず、するどく。

| 項目 | 内容 |
|---|---|
| タイプ | あく ／ みず |
| もとの 生き物 | ダイオウイカ |
| 分類 | しんかいの おう モンスター（第1形態・約57×59） |
| 性格 | 冷酷で 欲深い。闇の 墨で 海を 黒く そめ、何本もの 触腕で 船ごと 引きずりこむ |
| すみか | 光の 届かない 深海の 谷。闇の 中で 無数の 目が 光る |

## 見た目
- 闇の 紫の ダイオウイカ。外とう（胴）の 先に 三角の ひれ、表面に 赤紫の 色素の 斑点
- 大きな 頭に 金色の よこ瞳の 目（G）：広い 金の 虹彩（黄・だいだい）の まん中に 横長の 四角い 黒瞳、白い 光、後ろが 上がる 上まぶたの 線。攻撃では 瞳が 細い 横一文字に なる
- **何本もの 太い 触腕**（数を 引いて 5本 に まとめ、太く した）。手前の 腕は 前へ 巻きあがり、獲物を ねらう
- **吸盤が 目玉**：腕の 内がわに 白目と 赤い ひとみの 吸盤が ならび、こちらを 見ている
- **デフォルメ（2〜3頭身）**：外とうを 短く 丸く、頭と 目を 大きく。触腕（見せ所）は 太く 大きい まま

## 足した もの／引いた もの
- 足した：目玉の 吸盤（あく）、闇の 墨、色素の 斑点
- 引いた：腕の 数（10本 → 5本）、長い 外とう（短く）、細い 触腕の 長さ

## まぜた もの と 似ている 点
- イカの 吸盤 ⇔ 目玉：どちらも「丸い 点の 列」。吸盤の 丸を そのまま 白目と ひとみに 置きかえた

## 見せ所
- 太い 触腕と そこに ならぶ 目玉の 吸盤。攻撃では 2本の 腕を 前へ のばして たたきつけ、闇の 墨を はく

## はなれている もの（意図的）
- 頭の 後ろの 水の しずく、攻撃の 闇の 墨は エフェクトなので はなれているのが 意図的
- 腕の 付け根は 頭の 中に 食いこませ、外とうも 頭に 重ねて つないである

## 色（GBA風・16色以内 → 13色）
輪郭 2（黒／濃い紫）・体 3（闇の 紫）・斑点の 赤紫・吸盤の 白目と 赤い ひとみ・目 2（金・だいだい）・墨 2（灰紫・水色）・白

## 動き
- 待機：ふわりと 上下し、腕が うねる。外とうが ふくらむ
- 移動：前後に ただよい、腕で 水を かく
- 攻撃：身を 引いて ため → 2本の 腕を 前へ のばして たたきつけ、闇の 墨を ふく → 墨が 広がる
- 被弾：外とうごと 後ろへ のけぞる
- ダウン：外とうが くずれて 沈み、腕が だらりと 地に のびる（目は ×）

## ゲーム上の 目安
- 体力と 攻撃が 高い・素早さは ひくい
- 技の 例：やみの すみ（あく、命中ダウン）、しめつけ（みず）、めだまの むれ（相手を ひるませる）
