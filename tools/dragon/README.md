# 手打ちドラゴン（試作・64x64・8bit風）

パーツ（頭・あご・目・角・ほお・胴＋首・前足・後ろ足・しっぽ・翼×2）を 1ドットずつ 打った 文字マップで 持ち、
アニメは パーツごとの 1ドット ずらし＋差しかえ絵（目・口・ほのお）で 作ります。回転は 使いません。

- `dragon.py` … パレット・各パーツ・コマごとの 動き（`FRAMES`）
- `render.py` … 重ねて 描く（`python render.py dragon out.png` → 一覧と 1コマずつの PNG）
- `dragon.gif` / `frames.png` … プレビュー

## GBA風 仕上げ（`gba.py` / `render2.py`）

参考：DOT ART PLAY「ポケモン風ドット絵の描き方」系の 記事（GBA版は 64×64・16色以内・左上から 光・輪郭は 黒＋濃い色）。
キャラクターの デザインは オリジナルで、技法だけを 取り入れています。

- 16色以内（輪郭 2・体 3・おなか 3・翼膜 3・角つめ 2・目ほのお 2）→ 実際は 15色
- 光の 当たる 側の 輪郭と 内側の 線は 黒ではなく 濃い緑（セルアウト）
- 体の 明るい色は 上・左の ふちだけに 残す（三日月の ハイライト）
- 翼膜の 色の さかいめは 市松模様（ディザ）、骨の 下には 影の 線

`python render2.py out.png` → `out_<コマ>.png`（88×76、余白こみ）と 8倍の 一覧
