# Pixel Monster Arena（auto-battle-game）

くさむらで モンスターを つかまえて、観客席のある **スタジアム** でリアルタイムバトルをする 2D ゲームです。
`index.html` 1 ファイル（HTML + JavaScript + Canvas、外部ライブラリなし）で動き、スマホのブラウザ向けに作っています。

> モンスター・わざ・名前・ドット絵はすべてオリジナルです（既存作品のキャラクターは使っていません）。

### せかいかん

ドラゴン・スライム・ゴーレム・グリフォン・ガーゴイル・ミノタウロス・妖精など、**ファンタジーの まもの** を モチーフに しています。
トレーナーは フードつき マントの 冒険者、つかまえるときは **ふういんクリスタル** で 封印します。

### ドット絵の しくみ

**モンスターの 絵は 画像生成AI（Stable Diffusion 系の SDXL-Turbo）で 下絵を 作り、ドット絵に 仕上げた もの** です（`index.html` の `AISpr`）。

1. 1体ごとに 「横向き・全身・ドット絵ふう」の 候補を 何枚も 生成し、既存作品の キャラに 似ていない ものを 目で 選ぶ
2. 背景を ぬいて（rembg）、なめらかに 縮小 → 16〜20色に 減色 → 外側に 濃い 輪郭 → ゴミの ドットを 掃除
3. 目だけは 手で 描いた ドットを 上から 置く（かわいさと まばたき用）
4. 1枚の 絵から、ドット単位の 変形（行の けずり／ふやし・ずらし・ななめ・上下反転）で 14コマの アニメを 作る
   （`idle0〜3` 呼吸／`blink` まばたき／`walk0〜3` はずみ／`atk0〜2` ため→とびこみ→もどり／`hit` のけぞり／`ko` ひっくりかえる）

絵の データは 色パレット＋ランレングスで `AISpr.DATA` に 入っています。生成と 変換の スクリプトは `tools/aigen/` に あります。

> 生成に 使った SDXL-Turbo は [Stability AI Community License](https://stability.ai/community-license) の モデルです。
> 個人・非営利の 利用は 自由、年商 100万ドル未満なら 商用も 無料ですが、商用で 使う ときは Stability AI への 登録が 必要です。生成した 絵の 権利は 作った 人に あります。

トレーナーは 図形から 自動で 描く `SpriteGen`、`HandPix`（手打ちドット絵）は 生成AIの 絵が ない ときの 予備です。

## あそびかた

1. 「はじめから」→ さいしょの あいぼうを 3 たいから えらぶ（サラマン／ルリスライム／マンドラ）
2. **くさむらへ**：やせいの モンスターと 1 たい 1 で たたかい、**クリスタル** を なげて つかまえる。HP を へらすほど つかまえやすい
3. **たいかいへ**：スタジアムで トレーナーと 3 たい 3 の しあい。4 しあい（1かいせん → けっしょう）勝ちぬくと ゆうしょう、つぎの カップへ
4. **へんせい**：パーティの じゅんばんを かえる（上から 3 たいが しゅつじょう）。7 たいめからは ボックスへ

### バトル

- **モンスターは じぶんで うごく**。あなたは ボタンで **わざ（4つ）／こうげき／かわす／こうたい** を しじする
- あいての わざには **赤い よちょう**（直線・円・足もと）が でる。**かわす** で 一瞬 むてきに なって よけられる
- わざは 自動で あいてを ねらう。近づく ひつようが ある わざは 自動で 近づいてから だす
- **オート** を ON にすると、わざえらびと かいひも AI に まかせられる
- **こうたい** で ひかえの モンスターと いれかえ（たいかい・くさむら どちらでも）。えらんでいる あいだも バトルは とまらない
  - 交代して 出てきた モンスターは **約1.6びょう スキだらけ**（うごけない・かわせない・うける ダメージ 1.3ばい）。交代のあとは 4びょう こうたい できない
  - あいての トレーナーも タイプが ふりだと 交代してくる。出てきた ところを ねらおう
- フィールドは しばふ／つち／コンクリート／みずべ の 4 しゅるい。みずべは みずたまりで うごきが おそくなる（みずタイプは はやくなる）
- 大わざは フィールドに **クレーター** や こげあとを のこす。観客は 大わざで もりあがる
- タイプは 18種類（2タイプの モンスターも いる）。あいしょうは 一般的な 18タイプ表と 同じ
  - ハブの「タイプあいしょう表」で 一覧を 見られる。バトル中は わざボタンに あいてへの あいしょう（ばつぐん！／いまいち／きかない）が 出る
- わざは 1たい 4つまで そうびできる（へんせい画面の「わざ」から えらぶ）。レベルが あがると あたらしい わざを おぼえる

### わざ（ランキング上位100）

対戦で よく使われる わざ上位100（PChamp DB「技使用率一覧」）を、内容を PokéAPI のデータで 確認して 実装しています。
一覧と 参考にした技の 対応は [docs/moves.md](docs/moves.md)。名前は オリジナルです。

- **命中100の わざ**：あいてを ねらう（弾は ゆるく追尾、ビームや足元の わざは 予兆の とちゅうまで 追う）
- **命中100未満の わざ（◎）**：あいてを 自動で 追わず、**方向・範囲を 指定する わざ**。予兆の あいだに うごけば よけられ、命中が ひくいほど 予兆が ながい。だした しゅんかんの 方向・いちに 固定される
- 追加効果も 再現：やけど・まひ・どく・もうどく・ねむり・こおり、ひるみ、能力ランク（±6）、吸収・反動、まもる、みがわり（デコイ）、みちづれ、カウンター系、ちょうはつ・アンコール・あくび、とんぼがえり系の交代、バトンタッチ、ステルスロック・まきびし・どくびし、おいかぜ、トリックルーム など
- リアルタイム用の 読みかえ：「1ターン」は 約3秒。持ち物は ないので、はたきおとす・ポルターガイストは そのまま ダメージ、トリックは「能力変化の いれかえ」
- データの 再生成：`python3 tools/gen_moves.py index.html`（`tools/top100-moves.json` から `index.html` と `docs/moves.md` を 更新）

PC では J=こうげき、K・L・U・I=わざ、Space=かわす、C=クリスタル、X=こうたい。

セーブは ブラウザの localStorage に 自動で 保存されます。

## ローカルで うごかす

`index.html` を ブラウザで 開くだけです。スマホ実機で ためすなら：

```sh
python3 -m http.server 8000
# → http://<PCのIPアドレス>:8000/ をスマホで開く
```

`index.html?speed=3` のように すると ゲーム速度を かえられます（動作確認用）。

## GitHub Pages で 公開する手順

1. このリポジトリを GitHub に push する（`index.html` がリポジトリ直下にある状態）
2. GitHub のリポジトリページで **Settings → Pages** を開く
3. **Build and deployment** の **Source** で「Deploy from a branch」を選ぶ
4. **Branch** で公開したいブランチ（例：`main`）とフォルダ `/ (root)` を選んで **Save**
5. 1〜2 分で ページ上部に 公開 URL が 表示される（例：`https://<ユーザー名>.github.io/auto-battle-game/`）

ビルドは不要です。`.nojekyll` を置いているので そのまま配信されます。
