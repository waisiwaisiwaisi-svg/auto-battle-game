# Pixel Stance Duel（auto-battle-game）

ドット絵風の見下ろしアリーナで、剣士「ルカ」と魔獣「グロムホーン」が 1 対 1 でリアルタイムに戦うオート戦闘ゲームです。
キャラクターは AI が自動で動かします。プレイヤーは画面下のボタンで **スタンス** だけを切り替えて勝利を目指します。

- `index.html` 1 ファイルだけで動きます（HTML + JavaScript + Canvas、外部ライブラリなし）
- スマホのブラウザ（縦持ち）向けのレイアウトです。PC でも遊べます
- キャラクターはすべてオリジナルのドット絵で、コード内の文字マップから描いています

## 遊び方

1. 「バトル開始」を押す
2. ルカが自動で戦うので、状況に合わせて下の 4 つのボタンでスタンスを切り替える
3. 敵の HP を 0 にすれば勝ち、ルカの HP が 0 になれば負け。終わったら「もう一度」か上部の ↻ でリスタート

PC ではキーボードの `1`〜`4` でスタンス切替、`R` でリスタートもできます。

### スタンス

スタンスを切り替えると **2.5 秒のクールダウン** が入ります（ボタン下のバーで残り時間を表示）。

| スタンス | 行動の傾向 | リターン | リスク |
| --- | --- | --- | --- |
| 回避重視 | 横移動・回避が多い | 予兆への反応が速く確実、無敵時間が長い、攻撃後の硬直をキャンセルして回避できる | 与ダメ ×0.7。決着まで時間がかかる |
| ガンガン攻める | 接近と攻撃ばかり | 与ダメ ×1.5、攻撃間隔が短い、移動が速い | 被ダメ ×1.3、予兆にほとんど反応しない |
| 様子見 | 間合いを保って待つ | 被ダメ ×0.65、敵の攻撃後の隙に突っ込んでカウンター ×2.3 | 普段は手数が少ない |
| 距離を取る | 離れて射撃 | 遠距離から一方的に削れる | 弾の威力が低い。離れると敵の突進を誘いやすい |

### 敵の攻撃と予兆

敵が攻撃する前に、アリーナ上に **赤い範囲** で予兆が表示されます。範囲の内側が塗りつぶされていき、満タンになった瞬間に攻撃が発生します。

- **なぎ払い**：前方の扇形
- **突進**：直線上を壁まで突っ込む（壁にぶつかると長めの隙）
- **叩きつけ**（HP 60% 以下）：周囲の円形

ルカが予兆に気づくと頭上に `!` が出て、スタンスに応じた確率・反応速度で回避します。
攻撃のあと敵の頭上で星が回っている間は **隙** です。様子見スタンスならカウンターのチャンス。
敵は HP 35% 以下で怒り状態になり、予兆が短く・攻撃頻度が高くなります。

## ローカルで動かす

`index.html` をブラウザで直接開くだけで遊べます。スマホ実機で確認したい場合は、同じネットワーク内で簡易サーバーを立てると便利です。

```sh
python3 -m http.server 8000
# → http://<PCのIPアドレス>:8000/ をスマホで開く
```

## GitHub Pages で公開する手順

1. このリポジトリを GitHub に push する（`index.html` がリポジトリ直下にある状態）
2. GitHub のリポジトリページで **Settings → Pages** を開く
3. **Build and deployment** の **Source** で「Deploy from a branch」を選ぶ
4. **Branch** で公開したいブランチ（例：`main`）とフォルダ `/ (root)` を選んで **Save**
5. 1〜2 分待つと、ページ上部に公開 URL が表示される
   - 例：`https://<ユーザー名>.github.io/auto-battle-game/`
6. その URL をスマホで開けば遊べます（ホーム画面に追加するとフルスクリーン風に遊べます）

ビルド工程は不要です。`.nojekyll` を置いているので、Jekyll による変換もされずそのまま配信されます。

## 開発メモ

ブラウザの開発者コンソールから、バランス確認用のシミュレーションを実行できます（描画なしで 1 試合を高速に計算）。

```js
__game.simulate('watch')   // 'evade' | 'aggro' | 'watch' | 'range' | 'smart'(状況に応じて自動切替)
// → { result: 'win', time: 54.2, playerHp: 31, enemyHp: 0, stats: {...} }
```

参考までに、各スタンス固定での勝率はおおよそ 45〜65%、状況に応じて切り替えると 75% 前後になるよう調整しています。
